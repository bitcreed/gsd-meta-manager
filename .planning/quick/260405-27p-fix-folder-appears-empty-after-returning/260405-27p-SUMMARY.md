# Quick Task 260405-27p: Fix folder appears empty after returning from markdown view

## Changes

### Root Cause
`ArchiveDepth::FileView` used a plain `usize` for `phase_idx`, which couldn't distinguish whether the FileView was entered from PhaseList (top-level file) or FileList (phase file). When ESC was pressed, the handler always transitioned to `FileList { phase_idx }`, showing wrong/empty content for top-level files.

### Fix
Changed `phase_idx` in `FileView` from `usize` to `Option<usize>`:
- `None` = top-level file (ESC returns to PhaseList)
- `Some(idx)` = phase file (ESC returns to FileList)

### Files Modified
| File | Change |
|------|--------|
| `src/archive.rs` | Changed `FileView` variant's `phase_idx` from `usize` to `Option<usize>` |
| `src/ui/screens/detail.rs` | Updated ESC handler (branches on `None`/`Some`), Enter handlers (set correct `Option` value), `'e'` key handler, and breadcrumb rendering |
