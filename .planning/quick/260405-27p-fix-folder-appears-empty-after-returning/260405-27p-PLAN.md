<objective>
Fix the bug where the archive folder appears empty after returning from viewing a markdown file. The root cause is that `ArchiveDepth::FileView` does not distinguish whether it was entered from PhaseList (top-level file) or FileList (phase file). When ESC is pressed, it always transitions to `FileList`, which can show wrong content or nothing when the file was a top-level milestone file (e.g. `v1.0-ROADMAP.md`).

Purpose: Correct archive navigation state restoration so ESC always returns to the correct parent view with the correct file listing.
Output: Working archive drill-down with correct back-navigation at all levels.
</objective>
