<objective>
Add deserialization and default handling for the GSD 1.4–1.8 `config.json` keys the
`GsdConfig` struct does not yet model, so the Cfg tab can read (and later edit) them
without dropping data on round-trip.

Purpose: The TUI parses each project's `.planning/config.json` into `GsdConfig` and
writes it back via `serialize_gsd_config` when the user edits the Cfg tab. Any key not
in the struct is silently lost on save. GSD 1.8.0 added the `claude_orchestration`,
`statusline`, `dynamic_routing`, `review`, `external_job`, and `capabilities` blocks
plus new `workflow.*` gates and top-level keys.

Output: Extended `src/state_reader/config_json.rs` (new nested structs + fields) with
tests proving deserialize and round-trip.

Scope guard: touch ONLY `src/state_reader/config_json.rs`. The Cfg-tab UI enumerates
fields explicitly in `build_defaults_entries` + toggle/edit setter match arms in
`src/ui/screens/detail.rs`; surfacing/editing these new keys in the UI is DEFERRED to
plan 9 (Item H, the UI plan). This plan only adds the data model. Do not edit any UI file.
</objective>

  <action>
    Add new `#[derive(Debug, Deserialize, Serialize, Clone, Default)]` structs, each field

    execution_backend: Option<String>, min_agent_sdk_version: Option<String> }`;
    `StatuslineConfig { show_context_tokens: Option<bool>, state_format: Option<String>,
    show_git: Option<bool> }`; `DynamicRoutingConfig { provider_escalation: Option<bool>,
    max_escalations: Option<u32> }`; `ReviewConfig { reviewer_instances:
    Option<serde_json::Value> }` (shape varies — count or list — mirror the existing
    `quick_branch_template: Option<serde_json::Value>` precedent); `ExternalJobConfig {
    submit_timeout_ms: Option<u32>, poll_timeout_ms: Option<u32>, artifact_dir:
    Option<String> }`; `CapabilitiesConfig { strict_known_registries: Option<bool>,
    auto_update: Option<bool> }`. Add these to `GsdConfig` plus the top-level scalars
    `phase_id_convention: Option<String>`, `claude_md_path: Option<String>`, `sub_repos:
    Option<serde_json::Value>`. Annotate every NEW GsdConfig field with
    `#[serde(default, skip_serializing_if = "Option::is_none")]` so unset keys are omitted

    null keys it never had). Add tests: deserialize a JSON blob containing all new blocks
    and assert the values; parse `{}` and assert all new fields are None; serialize a
    default `GsdConfig` and assert the output does not contain `claude_orchestration`,
    `statusline`, `external_job`, etc.
