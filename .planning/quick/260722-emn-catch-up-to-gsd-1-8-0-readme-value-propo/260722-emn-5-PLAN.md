<objective>
Add a synchronous `project_last_activity` primitive that derives a project's
last-activity timestamp from its most recent git commit time, with a filesystem-mtime
fallback for non-git or empty repositories.

Purpose: Project staleness should survive `git clone`, `cp -r`, and `touch`, none of
which preserve or reflect real work timing the way commit dates do. File mtimes are the
only current signal and they lie after a clone/copy. This plan delivers the reusable
primitive; plan 6 (mod.rs) stores its result on `ProjectState.last_activity`.

Output: `src/state_reader/git_ops.rs` gains `project_last_activity(project_root) ->
Option<chrono::DateTime<chrono::Utc>>` plus helpers and inline tests.

Scope guard: touch ONLY `src/state_reader/git_ops.rs`. The wiring into `ProjectState`
and any UI display is DEFERRED to plan 6 (mod.rs, E→F1 handoff) and plan 9 (UI). Make
the function SYNCHRONOUS (use `std::process::Command`, not tokio) because its consumer
`parse_project_state` is synchronous. Do not edit any other file.
</objective>
