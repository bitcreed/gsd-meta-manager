<objective>
Fix the tmux pane TTY match bug in `src/terminal_switch.rs::switch_to_session`. Today it picks
the first `tmux list-panes -a` line whose `#{pane_tty}` merely CONTAINS the session TTY
(line 268), so a Claude session on `pts/1` can focus the pane on `/dev/pts/12` (or `/dev/pts/10`,
`/dev/pts/100`, ...) whenever that pane is listed first, and an empty TTY would match every pane.
Replace it with an exact match: strip a leading `/dev/` from `pane_tty` and compare for equality.

Purpose: the Tab/switch action lands the operator's keyboard in a pane. Focusing the wrong pane
means keystrokes (including tool-call approvals) go to an unrelated agent session.

Output: exact-match predicate extracted as pure helpers so the regression is testable without a
tmux server; regression tests `pts/1` vs `/dev/pts/12` (must NOT match) and `pts/1` vs
`/dev/pts/1` (must match) plus an ordering fixture and an edge-case table; doc contracts
corrected in both files.
</objective>
