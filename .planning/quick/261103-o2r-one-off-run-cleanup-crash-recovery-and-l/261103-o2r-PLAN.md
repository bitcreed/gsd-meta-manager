<objective>
Kill the leftover one-off run dirs and land back where a run came from (CONTEXT D-A, D-B, D-C, item 4).

Purpose: today a landed run keeps its ~115 MB `--no-hardlinks` clone until a manual `task land discard`; a run whose launcher died keeps its clone, locks and record forever; and `task land merge` lands into whatever branch happens to be checked out instead of the branch the run was dispatched from.

Output: dispatch-target recording and target-aware landing (`--into`, update-ref for a not-checked-out branch), post-landing / post-push slimming to a small record, landing from the tracked branch once the clone is gone, a crash/orphan/retention recycle scan wired into `task list`, `task run` and TUI start, CLI/TUI display of the target and the slim state, and the docs/help that go with them.
</objective>
