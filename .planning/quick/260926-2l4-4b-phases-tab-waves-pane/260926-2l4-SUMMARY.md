## What the Waves pane shows

- **Title** ([I-9]): ` Waves {n} · plans {d}/{t} done · est {E} act {A} ` (totals dropped first when narrow); not started: ` Waves {n} · {t} plans · not started `; flat: ` Plans (no wave metadata) · {d}/{t} done `; no plans: ` Waves · no plans ` with body `No plans yet — /gsd:plan-phase N`. ` · no live agents` appended when the active phase is part-done and no agent view covers it. Focused: cyan border and `▸Waves…` (focus_block).
- **Plan row**: `cursor(2) indent glyph word id title  act/est`. States: `✓ done`, `▶ running`, `◐ leftover`, `! stalled`, `· queued`, `○ planned`; each glyph 1 cell and distinct (pinned). Word drops first, then tokens, title shrinks with `…`; glyph + id never drop.
- **Wave header**: `▸ w11  3 parallel · 1 running · 2 queued` (current: ▸ + BOLD) / `  w13  2 parallel · queued`; `· Nf` when the manifest lists files.
- **Merged row**: `w1–w10 ✓ 28/28 done`, or `w3  1 plan · done ✓` for a single wave.
- **Windowing**: focused follows the cursor (offset kept in `waves_offset`); unfocused anchored one row above the current wave; `↑ +N more` / `↓ +N more` when clipped (height ≥ 3).
- **Four shapes (D-03)**: NotStarted (all waves open, `○ planned` off the active phase), Complete (one merged row), NoWaveMetadata (flat list, no headers), NoPlans (hint line).
- **Stage block ([I-12])**: line A `Discuss ✓  Research –  Plan 7  Execute 3/7  Verify –`; line B `Checks ✓Patterns ✓Plan-Check … +N not run` from the single `substage_table`.

## Pane key map (final)

| Key | In the Waves pane |
|-----|-------------------|
| `j`/`↓`, `k`/`↑` | move the row cursor, clamped; `↑` on the first row stays in the pane |
| `PgDn`/`PgUp` | page by the last rendered row count (1 before the first frame) |
| `g` / `G` | first / last row |
| `Enter`/`Space` | header or merged row: flip the fold of every wave it covers; plan row: jump to its agent (Sessions › Agents), else `No agent is attributed to this plan` |
| `e` | plan row: `SuspendAndEdit(<phase dir>/<id>-PLAN.md, objective_line)`; header: `Move to a plan row to edit its PLAN.md`; missing file: `No PLAN.md found for this plan`; no plans at all: falls through to the tab's generic enqueue |
| `←`/`Esc` | back to the phase list (Content) |
| `q` | leave the detail view (Pop) |
| `→` | no-op |
| `?`, `Tab` | focus-neutral, run as usual |
| digits, `D`, `[`, `]` | focus → Content, then run there (4a I-2 rule) |
| anything else | consumed, no-op |

Entry: `→` or `Enter`/`Space` on the phase list. Footer while focused: `[←/Esc]phases  [j/k]move  [Enter]expand/agent  [e]dit plan  [q]uit  [?]help`; Pipeline content footer prefix is now `[↑]tab bar  [←]tabs  [→/Enter]waves`.

## Cross-jumps (D-05, navigation only — T-2l4-04)

- **Agents → Phases**: `Enter` on an agent row (a child line uses its parent) → `pipeline_selected` = the plan's phase index (by `phase_key`), `share_pipeline_selection`, `switch_to_tab(Pipeline)` (the one arrival rule), `waves_cursor = Plan(stem)` resolved by equal `plan_index`, the plan's wave flipped open if folded, focus = Pane. Worktree-less/unattributed line → `This agent is not attributed to a plan`, no tab switch. Phase not in project → `Plan {label} is not a phase in this project`. Test asserts the returned action is `None` and the AgentView is unchanged.
- **Phases → Agents**: `Enter` on a pane plan row → the running (Live/Idle) row attributed to the plan, else the first attributed row; `switch_to_sub_view(Agents)`, `agents_selected` = its list line (`agent_line_index`), focus = Content.
