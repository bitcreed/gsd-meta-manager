## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository contents -> registry | `.git` gitfiles and `commondir` files are written by whatever repository a session cwd points at, including cloned/hostile repos |
| config.json -> startup prune | persisted registry entries are rewritten by the prune path |
| refusal text -> terminal | refused and main paths come from the filesystem and are echoed to CLI stderr and the TUI |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-x0v-01 | Denial of Service | registry structural classifier | medium | mitigate | Only regular-file `.git`/`commondir` are opened (FIFO/socket/device classified NotLinked without opening, so the TUI event loop cannot block); reads capped at 4096 bytes |
