<objective>
Add Tab-to-switch session focus, mirroring claudectl's tmux integration:
- From the project list, Tab on a row jumps focus to that project's
  active Claude session (if any).
- From the Sessions tab, Tab on a row jumps focus to that session.
- Tmux-first; gracefully no-op (with status message) outside tmux or
  when no matching session is on disk.
</objective>

<context>
~/projects/rust/claudectl/src/terminals/tmux.rs uses
  tmux list-panes -a -F '#{pane_tty} #{session_name}:#{window_index}.#{pane_index}'
to find which pane owns a given TTY, then runs
  tmux select-window -t <target>
  tmux select-pane -t <target>

Our ClaudeSession (src/session_detector.rs) has pid + working_dir but
no tty. /proc/<pid>/fd/0 symlinks to the controlling TTY (e.g.
/dev/pts/3) — we can read it without spawning extra processes.

The Tab key is currently unused on both the project-list overview
and the project-detail Sessions tab.
</context>
