`src/ui/screens/mod.rs`, regression tests on the sentriq-shaped fixture, flat projects unchanged.

Inferred decisions (human unavailable; for later audit):
- [INFERRED — audit] Precedence is Blocked > Active > Idle > Unknown > Complete. Blocked outranks
  Active because it is the strongest attention signal (red) and the active workstream stays visible on
  its own tinted line; Active outranks Idle ("most-active wins"); Unknown outranks Complete because a
  scope whose status cannot be read is not demonstrably done, and the bug is precisely a project
  counted done while a scope is not.
- [INFERRED — audit] `classify_status`'s vocabulary is NOT changed. sentriq's v0.13 status
  `human_needed` stays Unknown: mapping it to Idle would also recolour flat projects carrying that
  status, and the item requires flat projects unchanged. The aggregate ranks Unknown above Complete,
  so v0.13 alone would still stop a `phase_complete` root from counting done.
- [INFERRED — audit] "sort" means the attention-first sort. Neither sort mode reads a status category
  today (alphabetical, or `attention_rank` over needs-attention / driven-and-live), so the sort accounts
  for workstreams through the attention evidence, not by adding status to the sort key, which would
  reorder flat projects.
- [INFERRED — audit] Only the two per-directory evidence flags (`paused`, `external_job_waiting`) are
  aggregated. Driver runs, launcher markers, last outcomes and sessions are keyed by alias / project
  path and have no workstream identity, so they stay project-scoped.
- [INFERRED — audit] Each workstream's own line keeps its own status tint (unchanged), and the Detail
  screen's Roadmap header status colour (detail.rs, item 261023-05g's territory) is not touched.
