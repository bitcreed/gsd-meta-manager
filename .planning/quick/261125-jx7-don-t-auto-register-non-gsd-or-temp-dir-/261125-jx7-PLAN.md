<objective>
Stop the TUI's session auto-registration from adding folders that are not real GSD projects or that live under the system temp dir. The confirmed incident: `cargo test` installs a fake `claude` shim (`tests/launcher_support/mod.rs`, `Fixture::build`) whose process name is `claude`; `session_detector::detect_sessions` picks it up, and `registry::auto_register_from_sessions` registered its bare `TempDir` root (`/tmp/.tmp8D6C3g`, which holds only `.planning/meta-manager/drivers/<run>/DIRECTION.md`) into the user's real `config.json`, where it later showed as Phase "(missing)".

Two guards, both in the product:
1. A root qualifies only when its `.planning/` holds a real GSD marker file. No marker helper exists in the codebase today (every check is a bare `.planning/` directory test; gsd-core itself keys `project_exists` on `.planning/PROJECT.md`), so this plan introduces one shared helper in `src/registry.rs` using the brief's four markers and reuses it from `launch_target::auto_register`.
2. Session auto-registration never registers a root under the canonicalized system temp dir. Manual `add` is unaffected.

Purpose: the registry only ever gains entries the user would recognise as projects; test runs and scratch dirs stay out of it.
Output: guarded registry entry points with unit tests, migrated existing tests, launch-target consistency, updated docs.
</objective>

/// Files whose presence directly inside `.planning/` marks a GSD project root.
pub const GSD_PLANNING_MARKERS: [&str; 4] = ["STATE.md", "ROADMAP.md", "PROJECT.md", "config.json"];

/// `root/.planning` is a directory holding at least one GSD_PLANNING_MARKERS entry as a regular file.
pub fn is_gsd_project_root(root: &Path) -> bool;

/// temp_guard_root(&std::env::temp_dir())
pub fn system_temp_root() -> Option<PathBuf>;

/// canon_or_raw(raw); None when the result is not absolute or has no parent (empty, relative, "/").
fn temp_guard_root(raw: &Path) -> Option<PathBuf>;

/// temp_root.is_some_and(|t| root.starts_with(t))  -- Path::starts_with is component-wise.
fn is_under_temp_root(root: &Path, temp_root: Option<&Path>) -> bool;

/// The existing loop, plus both guards. `None` disables the temp guard.
pub fn auto_register_from_sessions_with_temp_root(

) -> Vec<(String, PathBuf)>;

/// Signature unchanged; body = system_temp_root() then delegate.
pub fn auto_register_from_sessions(config: &mut Config, sessions: &[ClaudeSession]) -> Vec<(String, PathBuf)>;
