B. Layout core (D1, D2). These rules are final unless a rule says Task 2 extends it.
1. Index. Map `phase_num::phase_key(id)` to the node index, first occurrence wins. Resolve each node's deps in declared order:
   - A dep whose key equals the node's own key is a self-cycle: drop it and record a cycle note.
   - A key found in the index is an in-graph dep. De-dupe by key, so `07` and `7` count once.
   - Anything else is external. Collect its escaped text, de-duped by key.
   Never compare ids by raw string equality (D1).
2. Cycles (D2, P11). Run an iterative DFS with white/gray/black colouring over dep edges. Start nodes in roadmap order and walk deps in declared order, using an explicit stack of (node, next-dep cursor). Never recurse. An edge to a GRAY node is a back edge. Drop it, and push the note `dependency cycle: <ids> (edges ignored)`. `<ids>` are the escaped ids on the stack from the gray target up to the current node, joined by `, `. A self-dep yields `dependency cycle: <id> (edges ignored)`.
3. Layers. Longest path over the remaining DAG edges, computed with a topological order such as Kahn's. `layer = 0` with no deps, else `1 + max(layer(dep))`.
4. Primary parent. A node's primary parent is its FIRST-DECLARED remaining dep whose layer is `layer - 1`. That dep exists by construction. P's primary children are the nodes whose primary parent is P, in roadmap order. Every other remaining dep edge is SECONDARY.
5. Rows. Keep a logical occupancy model per row: one node slot per layer, and one gap slot per adjacent layer pair. Task 2 extends this model with a junction cell per gap; design it so that extension adds fields rather than restructuring.
   - Roots are processed in roadmap order. Each root starts on a fresh row: row 0 for the first, otherwise one below the lowest row used so far.
   - A chain is a node followed by its first primary child, that child's first primary child, and so on. The whole chain goes on one row, and its gaps are marked used by that straight edge.
   - Queue every non-first primary child as a pending branch. Take pending branches deepest-layer first, breaking ties by lower roadmap index. Branches spawned by newly placed chains join the queue. Drain a root's queue before starting the next root.
   - In this task a branch child's chain goes on a fresh row below everything, starting at the child's own layer column, and its primary edge is emitted as a reference row. That fresh-row-plus-reference-row placement is the permanent fallback Task 2 keeps for branches that cannot be joined with a junction.
   - Every secondary edge is emitted as a reference row. Task 2 turns adjacent-layer secondary edges into fan-in where possible.
6. Columns. Layer width is the max escaped label width in that layer, minimum 1. Every gap is 4 cells: space, `─`, `►`, space. Task 2 widens gaps that hold a junction to 6. `col_start[k]` accumulates across layers.
7. Painting. Paint rows into a cell grid, then merge runs into `Segment`s. Nodes become `Node`, edge glyphs `Edge`, blanks `Space`. Trim trailing blank cells.
   - A node whose row has an outgoing straight edge is followed by exactly ONE space, then `─` through its padding cells and the gap's leading cells up to the arrow. For example, a 1-wide label in a 3-wide column gives `2 ───► ` (planner-inferred PI-2).
   - A node without an outgoing edge is padded with spaces.
8. Reference rows go after all node rows, ordered by target roadmap index and then by source declaration order. The row holds `Reference` for the source at its layer column, then a space, then `─` up to `target_col - 2`, then `►` at `target_col - 2`, a space, and `Reference` for the target at `target_col`. See O5.
9. Notes. First comes ONE external line, if any external deps exist: `external deps: ` followed by `<id> ◄ <dep>[, <dep>…]` groups in roadmap order, joined by `; `. Cycle notes follow it.
10. Detail. When `current` is Some(i), set `detail = Some(format!("▶ P{}: {}", escaped id, escaped name))`, with no truncation. Also set `current = Some(CellSpan)` to the node's row, `col_start` and label width. When `current` is None, there is no detail line (PI-5).
