<objective>
Fix Phase 21 R13-CR-01 (filed as CR-01 in the todo). `claude` documents `-r, --resume [value]`, so its value is
OPTIONAL. An element after a bare `--resume`/`-r` that looks like an option is therefore parsed by `claude` as a new
option, not as the resume value. `session_id_in_cmdline` (src/session_detector.rs ~726-734) binds that successor
unconditionally anyway. The result is mis-detection: `claude --resume --dangerously-skip-permissions` produces a
Sessions-tab row offering to resume a conversation that does not exist, and `claude -r -p --session-id <uuid>` hides
the real assigned id. Today a pinning test certifies the wrong model, and so does a generated property whose split-form
encoders share it.

Purpose: the detector should report the id `claude` actually bound, and the certificates should be able to fail
on this class.
Output: the parser fix, the rewritten and renamed pinning test, an option-shaped oracle branch in the generated
round-trip property, the partitioned enumerated SPLIT arm, CORRECTED doc blocks, and the todo closed.

Inferred decisions (human unavailable). Each one is marked `[inferred — cleanup 2026-10-28]`:
- I1. A refused successor is NOT stepped over. This follows the todo's "do not step over it". The 21-REVIEW snippet
  advanced the index, which would skip `--session-id` in `-r --session-id <uuid>`.
- I2. The single byte `-` stays a value, as the todo specifies and as commander-style parsers treat it. At 2.1.312
  this cannot be probed either way, because `--version` fires whether or not `-` was bound.
- I3. A negative-number-shaped successor (`-r -5`) counts as option-shaped. Measured during planning,
  `claude --bogus-opt --version` also prints the version, so `claude -r -5 --version` does not show whether `-5`
  was bound. This is disclosed as a residual whose direction is under-detection if `claude` binds it. It is not
  widened into a special case.
- I4. The split forms get their own oracle branch, not just an exclusion, so the certificate goes red under the old
  model instead of going silent.
- I5. The pinning test is renamed, because its old name states the falsified rule.
- I6. The todo closes into `.planning/todos/completed/`, not `.planning/todos/done/`. `completed/` is where GSD's
  add-todo/check-todos workflows and this project's history put closed todos, and `done/` is an empty leftover from
  March 2026. The batch prompt asked for "the GSD way".
- I7. `WireForm.optional_successor` is the per-option arity seam the CR-02 todo asks for.
</objective>
