<objective>
Extend the Defaults tab so it covers the latest GSD config keys
(intel.enabled, graphify.enabled, graphify.build_timeout), supports
typing into string fields like base_branch, and lets the user clear
optional values with the 'x' shortcut.
</objective>

<context>
@CLAUDE.md
@src/state_reader/config_json.rs
@src/ui/screens/mod.rs
@src/ui/screens/detail.rs

GSD config-schema.js (sdk/dist/query/config-schema.js) lists
intel.enabled, graphify.enabled, graphify.build_timeout as valid
exact-match keys; they're not yet in our GsdConfig struct.

The Defaults tab already supports dropdown-on-Enter for Bool/Enum
rows. String rows are inert; integer rows cycle. Optional fields
have no way to be set back to (unset) once a value is committed.
</context>

<tasks>
  <task id="T1">
    Extend `GsdConfig` with `intel: Option<IntelConfig>` and
    `graphify: Option<GraphifyConfig>`. `IntelConfig` exposes
    `enabled: Option<bool>`. `GraphifyConfig` exposes
    `enabled: Option<bool>` and `build_timeout: Option<u32>`.
  </task>

  <task id="T2">
    Add Intel and Graphify rows to `build_defaults_entries`,
    plus the wire-up for `set_config_value` and (for the integer)
    `mutate_config_entry`.
  </task>

  <task id="T3">
    Add `defaults_text_buffer: String` to `ProjectViewCache`.
    When Enter is pressed on a `ConfigValueKind::String` row,
    open a text-input popup pre-filled with the current value
    (empty if unset). Char/Backspace edit the buffer, Enter
    saves via a new `set_string_value` handler, Esc cancels.
    Wire keys: `base_branch`, `phase_branch_template`,
    `milestone_branch_template`, `quick_branch_template`,
    `project_code`, `phase_naming`, `response_language`.
    Empty submission clears the field to (unset).
  </task>

  <task id="T4">
    Add 'x' key handler in the Defaults tab. When no popup is
    open and the selected row is clearable, set the field to
    None (or unset the parent's `Option<...>` field) and save.
    Required scalars (`mode`, `granularity`, `model_profile`)
    are NOT clearable — the keystroke is ignored on those rows.
  </task>

  <task id="T5">
    `cargo build`, `cargo clippy`, `cargo test` — all clean.
  </task>
</tasks>
