**Data types (per RESEARCH.md recommendations):**

```rust
#[derive(Debug, Clone, PartialEq)]
pub enum ArchiveDepth {
    MilestoneList,
    PhaseList { milestone: String },
    FileList { milestone: String, phase_idx: usize },
    FileView { milestone: String, phase_idx: usize, file_idx: usize },
}

impl Default for ArchiveDepth {
    fn default() -> Self { Self::MilestoneList }
}

#[derive(Debug, Clone)]
pub struct MilestoneArchive {
    pub version: String,
    pub top_level_files: Vec<ArchiveFile>,
    pub phases: Vec<PhaseArchive>,
}

#[derive(Debug, Clone)]
pub struct PhaseArchive {
    pub number: u32,
    pub name: String,
    pub display_name: String,
    pub files: Vec<ArchiveFile>,
}

#[derive(Debug, Clone)]
pub struct ArchiveFile {
    pub name: String,
    pub path: std::path::PathBuf,
}
```

**Discovery function** - `pub fn discover_milestones(milestones_dir: &Path) -> Vec<String>`:
- First, check if `milestones_dir` exists and is a directory. If not, return an empty `Vec<String>` immediately. This handles the "Archive directory not found" UI state gracefully.
- Scan `milestones_dir` for files matching pattern `v*-ROADMAP.md`
- Extract version string by stripping `-ROADMAP.md` suffix
- Sort versions naturally (split on `.`, compare numeric parts: "v1.0" < "v1.1" < "v2.0")
- Return `Vec<String>` of version strings like `["v1.0", "v1.1"]`

**Loading function** - `pub fn load_milestone_archive(milestones_dir: &Path, version: &str) -> MilestoneArchive`:
- Top-level files: scan `milestones_dir` for files starting with `{version}-` (e.g., `v1.0-ROADMAP.md`, `v1.0-REQUIREMENTS.md`, `v1.0-MILESTONE-AUDIT.md`). Create `ArchiveFile` for each with absolute path.
- Phases: scan `{version}-phases/` directory for subdirectories. Parse directory names as `{NN}-{slug}` format. For each phase directory, list all `.md` files as `ArchiveFile` entries. Sort phases by number. Set `display_name` as `"Phase {NN}: {slug}"` with slug converted from kebab-case to Title Case (e.g., `core-infrastructure` -> `Core Infrastructure`).
- Sort top-level files alphabetically by name.
- Sort files within each phase alphabetically by name.

**File content reader** - `pub fn read_archive_file(path: &Path) -> String`:
- Read file content with `std::fs::read_to_string`
- On error, return `"Could not read file: {filename}"` (per UI-SPEC.md error copy)

**Markdown renderer** - `pub fn render_markdown_lines(content: &str) -> Vec<Line<'static>>`:
Per locked decisions from CONTEXT.md and UI-SPEC.md typography:
- Track `in_code_block: bool` state, toggled by lines starting with triple backtick
- Code block lines (including the backtick delimiters): `Style::default().fg(Color::DarkGray)` (per UI-SPEC: "DarkGray fg" for code blocks)
- `# heading` (after stripping `# `): `Style::default().fg(Color::Cyan).add_modifier(Modifier::BOLD)`
- `## heading` (after stripping `## `): `Style::default().add_modifier(Modifier::BOLD)`
- `### heading` (after stripping `### `): `Style::default().add_modifier(Modifier::BOLD | Modifier::DIM | Modifier::UNDERLINED)` (per CONTEXT.md locked decision: "Bold + dim underline for ###")
- Check `###` before `##` before `#` to avoid prefix matching issues
- For non-heading, non-code-block lines: call `parse_inline_styles(line)` helper
- `parse_inline_styles`: split on `**` delimiter pairs to create mixed spans - text between `**...**` gets `Modifier::BOLD`, text outside gets default style. Also, lines starting with `- ` are rendered as-is (already have bullet prefix in source per locked decision).
- Return `Vec<Line<'static>>` - all strings must be owned (`.to_string()`) since the function returns `'static` lifetime.
