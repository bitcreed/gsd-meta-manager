## Pattern Assignments

### `src/launcher/egress/mod.rs` (service, streaming)

**Analog:** `src/driverctl/serve.rs`

**Thread + current-thread tokio runtime + ready handshake** (L643-665). Copy this shape for `EgressServer::start`. The caller blocks until the listener is bound, so the egress socket exists before bwrap starts.
```rust
pub(crate) fn install_signal_handlers(stop: &Arc<AtomicBool>) -> Result<(), DriverctlError> {
    let (tx, rx) = mpsc::channel();
    let stop = Arc::clone(stop);
    std::thread::Builder::new()
        .name("driverctl-signals".to_owned())
        .spawn(move || {
            let runtime = tokio::runtime::Builder::new_current_thread()
                .enable_all()
                .build();
            match runtime {
                Ok(runtime) => runtime.block_on(wait_for_stop_signal(stop, tx)),
                Err(e) => {
                    let _ = tx.send(Err(e.to_string()));
                }
            }
        })
        .map_err(|e| io_error("spawn the signal thread", e))?;
    match rx.recv_timeout(Duration::from_secs(5)) {
        Ok(Ok(())) => Ok(()),
        Ok(Err(e)) => Err(io_error("install signal handlers", e)),
        Err(e) => Err(io_error("install signal handlers", e)),
    }
}
```

**Private socket bind (0600, staged then renamed, sun_path checked)** (L557-580): `bind_private` stages the bind in a 0700 tempdir, calls `check_sun_len`, chmods 0600, renames into place and sets the listener non-blocking. Reuse it, or `bind_run_socket` L590-594, for `$XDG_RUNTIME_DIR/gsdmm-egress-<hash8>.sock` (D-09). Convert with `tokio::net::UnixListener::from_std`. The hash is `serve::hash8(&canonical_run_dir)` (L272-275).

**Connection cap with an in-flight guard** (L779-805): `in_flight.fetch_add(1) >= MAX_CONNECTIONS` → refuse; otherwise an `InFlight` guard is dropped when the handler ends. In tokio, use the same counter or a `tokio::sync::Semaphore` with cap 64 (RESEARCH Pitfall 6).

**Stop:** a `stop: Arc<AtomicBool>` plus `JoinHandle`, as in `accept_loop`'s `while !stop.load(...)`. `run.rs` stops the server after `supervise` returns and before `finish_launch`.

**Async rule:** every `async fn` in this module is scanned by `tests/async_blocking_guard.rs`. Don't put a blocking call (`std::fs::*`, `std::thread::sleep`, sync `flock`, `Command`) lexically inside one. The per-request host-token re-read (Pitfall 4) must therefore go through `spawn_blocking` or use `tokio::fs`. Precedent: `serve.rs` L615-618, the doc comment "An `async fn` with no blocking call in it (`tests/async_blocking_guard.rs`)".

**Analog:** `src/launcher/host.rs` (pure parse + decide, typed outcome)

fn header_safe(value: &str) -> String {
    let cleaned: String = value
        .chars()
        .map(|c| if matches!(c, '\n' | '\r' | '|') || c.is_control() { ' ' } else { c })

## Shared Patterns

### Pure builder + one documented impure gatherer
**Source:** `src/launcher/sandbox.rs` L1-7, L216-219
**Apply to:** sandbox.rs, home.rs, egress/policy.rs, managed.rs content builder, host.rs absent-protections
> "Nothing here touches the file system, the clock or the environment: every host fact is a parameter (the one exception is [`SandboxSpec::from_host`], which says so)."

### The single spawn file
**Source:** `src/launcher/process.rs` L1-9; `tests/spawn_seam_guard.rs` L112-121 (markers `Command::new(`, `CommandWrap::with_new(`, `process_group(`)
**Apply to:** bridge.rs (claude child), home.rs (git config reads), host.rs (overlay probe), push.rs. Every spawn goes through a `process.rs` function. Don't touch the guard's allowlist.

### No blocking inside `async fn`
**Source:** `tests/async_blocking_guard.rs` header; precedent `serve.rs` L615-618
**Apply to:** every `async fn` in `src/launcher/egress/`. File reads (host token, log appends) go through `spawn_blocking` or `tokio::fs`.

### Typed refusals with stable reason strings
**Source:** `src/launcher/push.rs` `PushOutcome::Refused { reason: &'static str, detail }` L97-100, `refused()` L404-409; `LauncherError` (mod.rs L92-162)
**Apply to:** the push planted gate, a managed-settings parse failure, egress policy verdicts (`Deny(String)` naming the class or type, never the secret).

### Additive persisted keys (no schema bump)
**Source:** store.rs L218-221 + L891-916; driver_frontmatter.rs L381-388 + L605-617
**Apply to:** `protections_absent`, `egress_allow`, `auth`, `planted`, `inference_requests`. Values go through `header_safe` on write and `quote` on emit. They are emitted only when set, and absent keys keep old blocks byte-identical.

### Header-safe / redacted logging
**Source:** store.rs `header_safe` L405-418, `log_launcher_event` L1424-1440; auth.rs redacted `Debug` L63-71; push.rs `redact_urls` L231
**Apply to:** egress/log.rs, planted LOG lines, the bridge (writes nothing). A token or header value never reaches a log, argv or `Debug`.

### Atomic private writes
**Source:** config_dir.rs `write_atomic` L153-160, `create_private_dir` L163-168; serve.rs `bind_private` L557-580
**Apply to:** the managed-settings file, the per-run gitconfig, the egress socket (0600), the egress log (open with `mode(0o600)` as at run.rs L1374-1379).

### Live probes are opt-in and skip with a reason
**Source:** tests/launcher_live_isolation.rs L1-18, L178-197; tests/launcher_sandbox.rs L249-271
**Apply to:** every bwrap, network or paid probe (D-24). Use `#[ignore = "…; run with -- --ignored --nocapture"]` and `println!("SKIP: …"); return;`. Print exit codes and counts, never host content. Run with `cargo test --no-fail-fast` (project memory).

### Planning-doc tagging
**Source:** every launcher module doc (e.g. config_dir.rs L139, L176-177)
**Apply to:** each new inferred decision in code comments and docs: `[inferred — audit]`.
