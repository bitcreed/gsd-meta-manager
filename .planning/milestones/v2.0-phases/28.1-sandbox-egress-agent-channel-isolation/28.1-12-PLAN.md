planted git config).

CI commands; this host has both targets installed.

hardening fixes with tests.

## Decision: TLS crates Linux-only, not a CI toolchain change `[inferred — audit]`

The alternative was to keep the crates unconditional. CI would then need a mingw install step for
the Windows leg, and macOS runners for the two apple legs. The release.yml comment avoids those
deliberately: "`cargo check` and clippy stop before the linker, so no foreign runner minutes are
spent". Those runners would add CI cost to compile code that no macOS or Windows build can ever run.
`run.rs` starts the egress server only for `Posture::BwrapScope`, which is Linux-only by
construction. Moving the crates also restores the portability constraint in CLAUDE.md for
`cargo install` users on macOS and Windows, who no longer need a C compiler.
**Reversibility:** reversible. Moving three Cargo.toml lines and one file's cfg attributes back
undoes it.
