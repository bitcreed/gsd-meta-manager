<objective>
Build planted-file detection as a pure file reader and put it in front of the host-side git that
the push step runs in the driver-written checkout (D-21 detection half, D-22, D-23), with an explicit
operator acknowledgement to clear a park and hardened git invocations (A4 regression).

Purpose: the push step is the one place the launcher itself runs git in a repository the driver
controlled; a planted fsmonitor, hook, filter or worktree pointer must never execute there.

Output: `src/launcher/push/planted.rs`, the gate and hardening in `push.rs`, `driver push --ack-planted`,
and real-binary tests in `tests/launcher_push.rs`. Recording findings at launch time is 28.1-09.
</objective>
