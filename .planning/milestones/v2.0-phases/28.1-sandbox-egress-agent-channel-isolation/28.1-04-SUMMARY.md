# Phase 28.1 Plan 04: Posture Data, Host Facts and Egress Config Summary

**Every 28.1 posture fact now has a home in state.json and a fixed, parseable place in the DIRECTION frontmatter, the host probes measure overlay and profile-namespace support, and a per-project egress allowlist is configurable, validated and documented (default empty).**

## New keys and emit order

Emitted right after `prompt_version`, each only when set (a block with none is byte-identical to before):
`auth`, `protections_absent`, `egress_allow`, `inference_requests`, `planted`.

- `auth`: `setup-token` | `host-token` (`TokenSource::posture`).
- `protections_absent` / `egress_allow` / `planted`: arrays of quoted items; an empty list emits `key: []` and parses back as `Some(vec![])`, distinct from an absent key ("not recorded").
- `inference_requests`: bare number.
- `begin_launch` removes `auth`, `protections_absent`, `egress_allow`; `planted` and `inference_requests` are run-cumulative and survive a new launch.
- `sandbox_missing` (host tool pieces) and `protections_absent` (protections) stay separate keys.

## Corrected D-27 vocabulary rule

`host::PROTECTIONS` (fixed order): `net-isolation`, `egress-proxy`, `token-injection`, `home-allowlist`, `run-tmpfs`, `planted-file-ro`, `managed-settings`, `registry-overlay`.
`protections_absent(posture, overlay)`: degraded lists all eight; bwrap-scope lists `registry-overlay` only when `!overlay`; `managed-settings` is never listed for bwrap. `HostCaps.overlay` = bwrap >= 0.11.0 AND a dry `--overlay-src /usr --tmp-overlay /usr -- true` exits 0, probed only when bwrap runs. The bwrap run-probe now unshares pid/net/ipc/uts (Pitfall 12), so a host forbidding them is refused as `bwrap` missing.

## Config key shape

`projects.<alias>.driver.egress = {"presets": [...], "hosts": [...]}` -> `driver_egress_allowlist()`; presets `rust`, `github-read`, `npm`, `python` as in CONTEXT D-07, then hosts, lowercased, first occurrence kept. Absent -> empty. Unknown preset, non-string, scheme/port/path/wildcard/IP/single-label host, and `api.anthropic.com` are `EgressConfigError` naming the entry. Documented in `docs/CONFIGURATION.md`.
