<objective>
Build the launcher-side egress server as a library: one unix socket per run that serves the
token-injecting inference reverse proxy (D-04, D-05) and the deny-by-default CONNECT proxy (D-06),
with every decision in pure, table-tested functions and a plain-TCP upstream seam so the whole
request path runs in CI against an in-process stub of `api.anthropic.com` (RESEARCH Pattern 1, 2).

Purpose: the token must live only outside the sandbox and the only network path out of the sandbox
must be a policy the driver cannot touch. Later plans bind this server into the launch (28.1-07)
and reach it from inside bwrap through the bridge (28.1-05).

Output: `src/launcher/egress/{mod,policy,http1,upstream,log}.rs`, four new crates with a measured
justification block, and `tests/launcher_egress.rs`.
</objective>
