(D-A01b): enumerate a project's agent worktrees with read-only, lock-free git, attach adapter facts
through a trait the core does not need to change for (D-A07), classify liveness in one place (D-C08),

parallel on top of this plan, so the contracts below are the interface both build against — the
executor keeps every public name and field exactly as written here.

`tests/agents_scan.rs`, and the AGENT requirement ids in REQUIREMENTS.md and ROADMAP.md.

`src/agents/claude.rs` (CONTEXT's discretionary suggestion). Registering an adapter is then a

Codex adapter (D-A08) never edits `src/agents/mod.rs`, the wave model or the UI — the D-A07 test
stated as a file boundary — and 25-02 and 25-03 get disjoint files for parallel worktrees.
