**Encoding (D-C05).** `encode_project_dir(path)` follows RESEARCH's verified algorithm: iterate `char`s, keep `is_ascii_alphanumeric` chars, emit `c.len_utf16()` dashes for every other char; when the result exceeds 200 bytes (it is pure ASCII, so bytes equal UTF-16 units), return its first 200 bytes plus `-` plus the base-36 lowercase rendering of `abs(h)`, where `h` is an `i32` folded over `path.encode_utf16()` as `h = (h << 5).wrapping_sub(h).wrapping_add(unit as i32)` and `abs` is taken in `i64` so `i32::MIN` maps to 2147483648. Write a private `to_base36(u64) -> String`.

Session directories are the subdirectories of each project directory.
