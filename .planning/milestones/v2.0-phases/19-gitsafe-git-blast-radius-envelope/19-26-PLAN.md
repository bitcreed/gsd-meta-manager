## The design question, answered — option (d), a SPLIT, and here is which carrier gets what

**(c) — move a carrier out of reach — is dead for every one of them, and saying that once is worth more
than four denials.** Every envelope carrier must be readable, writable or executable by the same uid the
driven process runs as, because git must exec the hooks, the agent CLI must read the settings and the
guard must append the ledger. There is no location on a single-uid model that the driven process cannot
also reach. A different uid, a container, or a remote-side control are the only real (c)s; the first two
are outside this phase and the third is what `SECTION_ENVELOPE`'s own conclusion already says.
