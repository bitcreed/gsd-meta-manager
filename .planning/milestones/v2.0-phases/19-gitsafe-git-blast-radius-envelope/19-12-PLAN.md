<objective>
**The control that has to survive the seventh wrapper nobody listed.**

Plan 19-11 closes T-19-60 structurally and proves it against the six lines `19-SECURITY.md`
measured. Six enumerated rows are the right RED corpus and the wrong final control: a corpus of
named instances is structurally incapable of failing on the class, so it would be green on the
day it lands and silent the day someone re-introduces a name list to close a new shape. This plan
adds the control over the CLASS.

The class is anything that changes which token is the effective program without appearing as the
first token. The property is that the guard's verdict is INVARIANT under it: wrapping a command
in any chain of any depth, spelled by basename or absolute path, prefixed with any assignments,
quoted any legal way, does not change what the envelope decides. That is asserted against a
right-hand side measured from the unwrapped command in the same run, so the property tightens
rather than loosens if the bases ever stop being refused.

Two things make it non-vacuous rather than merely large. The alphabet contains names that appear
nowhere in `src/` — including one that exists only in this file — and a control asserts their
absence, so a fix that became a list fails its own corpus. And the same generator runs over a
corpus of commands that must be PERMITTED, so a guard that refused everything would fail here
rather than look green (D-32).

Purpose: make the closure of T-19-60 a property a later reader can trust, and bound the one
residual it does not close so its edges are visible.
Output: `tests/envelope_wrapper_class.rs`.
</objective>
