<objective>
Close SAFE-03 and the `git add -A` worktree-sweep hazard: a driven push carrying a detectable
credential is blocked before it leaves the machine — including a credential written to a path the
repository's ignore rules cover — and a driven commit cannot sweep `.claude/worktrees/`,
`.planning/meta-manager/runs/` or a nested repository into the tree (SAFE-03, D-11 through D-15,
D-21 through D-23).

Purpose: these are the two hazards this phase can actually close on the client side, and both have
a named blind spot that the obvious implementation walks straight into. A diff-based scanner
misses exactly the paths a secret is most likely to be written to; a declined worktree isolation is
not an answer to a `git add -A` sweep. Both are closed mechanically here.

Output: `src/envelope/scan.rs`, a class-tagged `PARTS` table with one consumer per class, a
pre-commit hook, a pre-push backstop, and an idempotent `.git/info/exclude` marker block.

Reversibility note: D-11 through D-15 and D-21 through D-23 are locked decisions in
`19-CONTEXT.md`. Ratings are recorded on the tasks; no `checkpoint:decision` is inserted.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| driven agent → worktree files | The agent writes arbitrary file content, including credentials, at arbitrary paths |
| worktree files → scanner → report | Untrusted file bytes cross into a report that is printed and journalled |
| driven agent → git index | The agent stages arbitrary paths, including nested repositories and the envelope's own runs directory |
| driven repository → `.git/info/exclude` | The envelope's one persistent write into a repository it does not own |
