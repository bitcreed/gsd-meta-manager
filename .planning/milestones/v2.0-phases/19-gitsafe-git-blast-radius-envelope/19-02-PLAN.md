<objective>
Turn D-08's denied set into a single pure function, `envelope::policy::classify_git(argv) -> GitVerdict`,
that is exhaustively unit-testable without a repository, a process or a network — and give the
envelope its configuration surface: four `#[serde(default)]` fields on `DriverOptIn`, a
`CredentialSource` enum, and one place where every default is decided (SAFE-02, D-08, D-30).

Purpose: layer 2 and layer 3 of the D-06 enforcement stack both need the same verdict, and a
policy that lives in two places is a policy that will eventually disagree with itself. Making it a
pure function over argv is what lets the whole denied set be proved by unit tests rather than by
spawning git thirty times.

Output: the complete SAFE-02 decision surface plus the envelope's config schema, with the
pre-Phase-19 migration proved by a byte literal.

Reversibility note: D-08 and D-30 are locked decisions in `19-CONTEXT.md`. Ratings are recorded on
the tasks; no `checkpoint:decision` is inserted for a door the developer has already walked
through.
