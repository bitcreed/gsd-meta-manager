## The rule, exactly

**A segment is refused when any of its words is ABSOLUTE, LITERAL, and — after LEXICAL normalisation —
equal to or under the envelope directory, compared COMPONENT-WISE.**

Each of the four conditions is a boundary rather than a convenience:

* **ABSOLUTE**, because the guard has no cwd. Direction (iv).
* **LITERAL** (`Token.literal`), because a word the shell may rewrite is a word the guard cannot
  resolve, and refusing every non-literal operand of an ungoverned command would deny `rm $TMPDIR/x`.
  Direction (ii).
* **LEXICALLY NORMALISED** — leading `./` stripped, repeated separators collapsed, `.` dropped, `..`
  collapsed TEXTUALLY, **no link followed** — because `<env>/alpha/hooks/../pr-ledger.ndjson` is the
  shape audit 9's own composite uses, and because `canonicalize`/`read_link` is I/O and TOCTOU on the
  guard's critical path. Direction (iii).
* **COMPONENT-WISE**, never a basename, an `ends_with`, a substring or a raw `starts_with`: `19-26`
  pinned `rm -f /tmp/pr-ledger.ndjson` and a one-character-different root PERMITTED, and a raw
  `starts_with` over `<root>/alpha` would also refuse a sibling named `alpha2`.

**Raised ONCE, at the top of `classify_segments`' existing per-segment loop, BEFORE
`resolve_program_with_head`.** On the segment the loop already holds, from the same walk — round 3's
principle discharged, not weakened. **Before the resolution match rather than inside the `Ungoverned`
arm**, because that arm covers `rm -f <ledger>` and misses
`git config --file <envelope>/alpha/gitconfig alias.x '<body>'`, which resolves `Governed` and never

`ParkReason::EnvelopeAssertionFailed`, **no new variant**, and deliberately **not**

2. **An EXPANSION-BORNE operand cannot be resolved.**

3. **A SYMLINK is not followed.** `..` is collapsed lexically; a link is not.
4. **A RELATIVE path is not resolved.** The guard has no cwd.

/tmp/l` and `cd <env>/alpha` each name an envelope path as their OWN operand and are refused, so a link
