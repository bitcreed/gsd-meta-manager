<objective>
Build the state layer the whole Driver surface stands on: a bounded ring buffer for live output, the
sanitiser that guards it, the predicate that decides a project needs a human, and the message types
the controller will dispatch.

Purpose: the ring buffer is **the first bounded in-memory collection in this repository** —
`grep -rn VecDeque src/` returns nothing today, so this is genuinely greenfield and there is no
precedent to imitate, only conventions (D-18). Two placement rules are load-bearing and both are
already stated four times in `screens/mod.rs`: driver state does **not** go on `ProjectState`,
because that type derives `PartialEq` and `app.rs` uses the derived equality to suppress the
"Updated: {alias}" status message — one 68-second spike turn emitted 22 `thinking_tokens` events, so
putting live state there would flood the status bar for an entire multi-hour run; and no map may
hold a file handle or a join handle, because `Action` derives `Clone`.

The sanitiser is the phase's highest-value security control. Agent prose lands in `ExecEvent.text`,
`Diagnostic.detail`, `RunRecord.goal` on re-read, and `gsd_command`; without an unconditional `ESC`
strip, that prose can emit ANSI/OSC sequences that repaint the screen, forge a status line, move the
cursor, or set the window title.

Output: `DriverOutput` and its caps, `sanitize_render_line`, `needs_human`, `SortMode`, the new
`AppContext`/`ProjectViewCache` fields, the new `Action` variants, and `FilterColumn::NeedsHuman`.
</objective>

Write the first bounded in-memory collection in this repository, and the sanitiser that feeds it.

Three named `pub const`s, each carrying the `main_loop.rs:41-49` doc register — what the number
bounds, and the sentence that it is a defensible starting value with **no tuning data behind it**,
named so tuning is a one-line change: `DRIVER_OUTPUT_RING_LINES` (2000, roughly 400 KB per alias),
`DRIVER_OUTPUT_LINE_CELLS` (512, a per-line hard truncation applied at append time by **character**
count), `DRIVER_OUTPUT_RECORD_MAX_LINES` (64, so one journal record that expands past it is cut and
a single giant record cannot flush the whole ring).

`DriverOutput` wraps a private `VecDeque<DriverOutputLine>`. `push_record(kind, raw)` sanitises,
splits, caps, pushes, and pops from the front while over the cap, incrementing a `dropped` counter.
Follow the `journal/writer.rs:97-118` cap asymmetry: the counter is the mechanism, not a per-drop
log — the render layer shows one first line naming the count and nothing else. Expose `lines()`,
`dropped()`, `len()`, `is_empty()`, `clear()`. The buffer holds only owned `String`s and plain data;
its doc must copy the two mandatory bullets from the `journal_cursors` doc — that it holds no file
handle and no join handle because `Action` derives `Clone`, and that **the map is pruned**, on the
same 20-tick block as the reconciliation probe.

`sanitize_render_line(raw) -> String` applies, in this order: replace every C0 control character and
`DEL` with the middle-dot glyph; expand tab to four spaces; **strip `ESC` unconditionally**; truncate
by `char` count to `DRIVER_OUTPUT_LINE_CELLS` with an ellipsis suffix. Byte slicing panics on a
multibyte boundary, so the truncation is a `char` operation and there is a test for exactly that.
`sanitize_record_lines(raw) -> (Vec<String>, bool)` splits on newline **first** — assistant output is
genuinely multi-line and is more readable split than collapsed — sanitises each line, and caps the
vector at `DRIVER_OUTPUT_RECORD_MAX_LINES`, returning `true` when it cut.

The doc on the `ESC` rule must state the threat plainly and name it as the single highest-value rule
in the boundary: without it, agent prose can emit sequences that repaint the screen, forge a status
line, move the cursor, or set the window title.

Inline `#[cfg(test)] mod tests`: pushing `DRIVER_OUTPUT_RING_LINES + 50` lines leaves exactly the cap
and reports 50 dropped; a record with 200 embedded newlines is cut to the record cap and reports the
cut; a 4-byte-per-char string longer than the line cap truncates without panicking; an `ESC`-bearing
string yields a result containing no `ESC`; a string of C0 controls yields only the replacement
glyph; a tab expands to four spaces. Test names are full sentences in snake_case and assertion
messages say what the failure means.
