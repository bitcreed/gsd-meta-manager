<objective>
Make the Phase 27 store and the Phase 28 gate enforce what the prompt asks: exactly one recovery decision
per running item before any dispatch (D-17), no new dispatch once the human paused or stopped the run
(D-18, RESEARCH OQ5), and the prompt version recorded on every launch (D-03 store half). Factor the
frontmatter derivation into a pure function `driver new` can call (D-09 store half).

Purpose: SC4 must not depend on the model remembering a rule; these are the mechanical halves of PRMT-04
and the persistence half of PRMT-01.

Output: store/gate/frontmatter changes, a binary-level D-17 test file, store and frontmatter goldens.
</objective>
