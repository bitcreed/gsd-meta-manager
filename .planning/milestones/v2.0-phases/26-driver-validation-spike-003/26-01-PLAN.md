**tools/drift.py — the moving target (VALID-01 seed).** A pure `emit(gen) -> (titles, expected)`. Generation 0 is about 20 plain titles a trivial slugify passes (lowercase; each run of non-alphanumerics becomes one hyphen; leading/trailing hyphens stripped), including `Hello World` → `hello-world` exactly once. Each generation k >= 1 appends 5-6 lines of one new house-rule class and never changes an earlier line; `MAX_GEN >= 8`. Class constraints: every expected slug matches `^[a-z0-9]+(-[a-z0-9]+)*$` (consistent with the scratch SLUG-01); no title appears twice; no class is derivable from earlier ones; and symbol rules are interleaved with non-symbol rules so a general symbol-to-word table written for one class cannot pre-pass a later one. Example sequence: `+` read as `plus` (C++ → c-plus-plus); `&` collapsed to `n` with no hyphens (R&D → rnd, AT&T → atnt); leading articles dropped (The Matrix → matrix); standalone digits 1-9 spelled out (3 Little Pigs → three-little-pigs); a house abbreviation table (Saint → st, Mount → mt); the executor fixes the final list, checks it against every earlier generation, and documents it in the docstring. `ref_slugify(title, k)` applies classes 1..k in order then the trivial rule; it exists only for `selftest` and is never written into a scratch project.
