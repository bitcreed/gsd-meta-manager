**tools/dup_check.py (VALID-03).** Sessions come from LOG.md `| RUN | connect | session=` lines (one per launch). For each session, load every `<cfg>/projects/*/<sid>/subagents/agent-<id>.meta.json` into nodes `{agentId (from the filename), agentType, parentAgentId, description, toolUseId, spawnDepth, finished}`. Workers are the nodes with no `parentAgentId`; each worker's descendants are found by walking `parentAgentId` links. Per worker, group descendants by `agentType` and flag DUP when there are more than one `gsd-planner`, more than one `gsd-verifier`, or more than one `gsd-executor` sharing a `description`; flag EXECUTOR_MISSING (reported, not a duplicate — spike 002 R2-2 ran a plan inline) when a worker has a `gsd-verifier` but no `gsd-executor`. Driver level: count `tool_use` blocks named `Agent` or `Task` (unique ids) and `SendMessage` in the main transcript `<cfg>/projects/*/<sid>.jsonl`; LOG_DISPATCHED = I-item `dispatched` lines, LOG_DENIED = `dispatch-denied` lines; add one DUP per top-level worker beyond LOG_DISPATCHED − LOG_DENIED (a re-spawn the driver did not log). When the LOG has no I-item `dispatched` line at all (a scripted cap-test driver such as L7, which never logs dispatches), skip this driver-level rule and print `driver_check=skipped` on line 1 instead of counting every worker as a re-spawn; acceptance's A6 audit still compares logged with observed dispatches. `--state` additionally cross-checks workers == `hook_dispatches` and prints a warning line on mismatch. **tools/stage_cost.py (VALID-04).** Rates per model are solved from the `result` event's `modelUsage` of the first given launch that has one (cost_split's method); `--rates-from` supplies another launch's stream when none has a result (a killed launch, RESEARCH Pitfall 9); with no rates at all it prints token counts, `priced=no`, and exits 2. Driver usage (main transcript, last usage per `message.id`) is bucketed by each message's `timestamp`; each worker's whole subtree (its own transcript plus all descendants) is bucketed by the worker transcript's first timestamp. Anything outside every window goes to `unbucketed`. Per-phase totals use the `phase=` field of each window's `dispatched` line. Print the contract lines; `CHECK` compares the sum of per-stage driver cost with the independently summed driver total and fails (exit 1) on a difference above $0.01.
