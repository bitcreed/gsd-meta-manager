## Egress architecture

| Option | Description | Selected |
|--------|-------------|----------|
| CONNECT allowlist proxy only (audit C1) | `api.anthropic.com` allowlisted; token in env | |
| Token-injecting reverse proxy for the API, plus a deny-by-default CONNECT proxy | dummy token inside; path filter allows only `/v1/messages`; body check | ✓ |
| seccomp AF_UNIX ban (sandbox-runtime) | blanket block of unix sockets | |

**Choice:** reverse proxy plus CONNECT proxy (D-04..D-06).
**Notes:**
- Evidence showed the token is readable via `/proc/<pid>/environ`. The account APIs (sessions,
  triggers, mcp_servers, bridge) share `api.anthropic.com` with inference, so a host allowlist can't
  contain them.
- seccomp was rejected because it breaks the driverctl hook socket.
- New channel found: `/run/docker.sock` was reachable even with `--unshare-net`. Fixed with
  `--tmpfs /run` (D-03).

## Agent tools & nested claude
