<objective>
Cut the sandbox off the host network so the 28.1-05 bridge is its only way out: a profile with
`--unshare-net/ipc/uts`, a fixed hostname, a tmpfs over `/run` and the run's egress socket re-bound
inside the runtime-dir tmpfs (D-02, D-03), plus the env contract that points Claude Code at the bridge
with a dummy token (D-04, D-09a).

Purpose: SC1's live proof — localhost, LAN, abstract and host filesystem sockets unreachable, API
reachable only through the launcher's proxy — at the library level, and A5 re-proved with the token
kept outside the sandbox; 28.1-07 wires it into `driver launch`. (Split out of the original 28.1-05 on
checker scope_sanity feedback as one capability slice, not by layer `[inferred — audit]`; it runs after
28.1-05 because its live probe executes the real `bridge` subcommand.)

Output: the new profile and env functions with goldens, live netns probes, and the A5 live test
rerouted through the proxy.
</objective>
