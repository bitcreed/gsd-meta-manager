### Gaps Summary

Two blockers, both small and independent:

1. **Body policy bypass (SC1 / LNCH-09 / T-28.1-02).** The proxy judges `serde_json`'s last-wins view of the body and forwards the original bytes. A sandboxed driver, which can write raw HTTP to the egress socket, can send a body whose judged view is clean and whose raw form carries a `web_fetch` tool or a URL-sourced block. This matters because those server tools make Anthropic's servers fetch on the driver's behalf, which is exactly the delegation channel the phase exists to close.
