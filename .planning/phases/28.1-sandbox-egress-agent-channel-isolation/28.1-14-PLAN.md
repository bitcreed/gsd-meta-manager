- **A verify-only wave-8 plan with a bounded repair rule.** It runs after all three wave-7 plans.
  It edits no source on the pass path. If a cross-target command fails on the merged tree, the cause
  is an interaction between wave-7 plans that no single worktree could see. The repair rule in
  Task 1 lets the executor fix only a missing platform gate in a file that 28.1-11, 28.1-12 or
  28.1-13 changed. Everything else stops the plan with the ledger untouched.

  text.

  `~/.local/bin` or `~/bin`. It defers the `install_root` parent fallback (`~/Downloads/node` binds

  than shipped. `deferred` with a reason that names both halves is accurate.

  Plans 11-13 only recommend deferring them to a follow-up `/gsd-code-review 28.1 --fix`, and WR-05
  explicitly needs an operator decision. A planner recommendation is not a recorded triage
  decision, so this plan does not record one.

  preserved together with its Source cell. code-review-disposition.md L361-373 keeps a prior row's
  disposition and Source while the finding title is unchanged. Re-running the review would regenerate
  `28.1-REVIEW.md`, which is out of scope here.
