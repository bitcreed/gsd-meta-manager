## Decisions `[inferred — audit]`

- **Order: PLANTED, then absent, then auth.** PLANTED points to probable tampering. `absent:` is
  the SC7 data the requirement names. `auth` is a posture with a remedy. Prompt, egress and api are
  context, and clipping may drop them.
- **No new header row.** The 30-03 height tiers stay as they are; plan 06's constraint holds.
- **`absent: all 8`** is shown only on exact set equality with the vocabulary. A hostile or garbled
  list can therefore never collapse into a summary that hides which words it holds; it is always
  shown verbatim and escaped.
- **The vocabulary moves to `src/launcher/mod.rs`.** That module root is ungated, and `LauncherError`
  already lives there for the same reason. Placing it there lets `driver_run.rs`, which compiles on
  Windows, read the vocabulary without depending on the linux/macos-gated `host` module.
  **Reversibility:** reversible. The re-export keeps every old path working.
