<objective>
Replace the `$HOME` denylist with an allowlist (D-16..D-20): a size-capped tmpfs over `$HOME`, then
read-only re-binds of exactly what a run needs, derived from the running host; a minimal per-run
gitconfig; registry overlay; and only GSD/rtk hooks kept in the per-run settings.

Purpose: B2 — any credential file the denylist did not name is readable today; with the network
gone it is no longer exfiltratable through the network, but it is still usable through every
allowlisted host and every file the operator reads later.

Output: `src/launcher/home.rs`, the `$HOME` block in `bwrap_argv`, run.rs wiring, the D-19 filter,
goldens, invariants and the live D-16 probe.
</objective>
