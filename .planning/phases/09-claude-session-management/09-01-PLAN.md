Create `src/session_detector.rs` with:

1. **ClaudeSession struct** (per D-06):
   ```rust
   #[derive(Debug, Clone)]
   pub struct ClaudeSession {
       pub pid: u32,
       pub session_id: Option<String>,  // from --resume UUID, None if new session
       pub working_dir: PathBuf,        // from /proc/PID/cwd
       pub start_time: Option<u64>,     // from /proc/PID/stat field 22 (starttime)
   }
   ```

2. **`detect_sessions() -> Vec<ClaudeSession>`** function (per D-01, D-02):
   - Run `pgrep -x claude` to get PIDs (use `std::process::Command`, NOT tokio — this is called from spawn_blocking)
   - For each PID, read `/proc/PID/cwd` via `std::fs::read_link`
   - For each PID, read `/proc/PID/cmdline` via `std::fs::read_to_string`, split on null bytes, look for `--resume` followed by a UUID argument to extract session_id
   - For each PID, read `/proc/PID/stat` and extract field 22 (starttime) for start_time
   - Return Vec of sessions, silently skip any PID where reads fail (stale PID handling per Claude's discretion)

3. **Add to src/main.rs**: `mod session_detector;`

4. **Add Action variant** in `src/action.rs`:
   ```rust
   SessionsDetected {
       sessions: Vec<crate::session_detector::ClaudeSession>,
   },
   ```

5. **Add `active_sessions` field** to `AppContext` in `src/ui/screens/mod.rs`:
   ```rust
   pub active_sessions: Vec<crate::session_detector::ClaudeSession>,
   ```
   Initialize as `Vec::new()` in `App::new()`.

6. **Add `session_poll_counter: u32` field** to `AppContext` (or App struct). Initialize to 0.

7. **Wire polling in `App::update` for `Action::Tick`** (per D-03):
   - Increment session_poll_counter
   - Every 20 ticks (5 seconds at 250ms interval), if event_tx is Some, clone tx and spawn_blocking to call `session_detector::detect_sessions()`, then send `Action::SessionsDetected { sessions }` back
   - Reset counter to 0 after dispatch

8. **Handle `Action::SessionsDetected`** in `App::update`:
   - Set `self.ctx.active_sessions = sessions`
   - Set `self.needs_redraw = true`
