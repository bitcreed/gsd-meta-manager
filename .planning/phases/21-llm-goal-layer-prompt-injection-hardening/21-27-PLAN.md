<objective>
**Round 10, wave 1. Delete the interpreter — do not learn to quote for it.**

Verification pass 10 confirmed CR-01 by reading the code rather than by trusting the
reviewer: `src/ui/screens/detail.rs:1692-1707` builds a program string for a command
interpreter out of two values scraped from another process's `/proc` entry, neither of
which passes through `is_identity_char` or any alphabet. A single quote in either
terminates the quoting and runs arbitrary code with the operator's privileges.

**The part that makes this a round-10 item rather than a round-1 one:** the shape predates
this phase (`867d277`, phase 9), but round 9's own diff touched these exact lines, retyped
the id, and added a comment classifying the value as a subprocess argument. It is not one.
It is a fragment of a program that an interpreter will parse. And `as_raw_for_logic_only`'s
own doc lists subprocess arguments among its accepted uses without ever distinguishing the
two — which is precisely why round 9's compiler-named-sites methodology, which is otherwise
the strongest mechanism this phase has built, could not see this site. **The vocabulary was
short by one question, so the site looked answered.**

So this plan does three things and they are one thing:

1. **Delete the interpreter.** argv, `Command::current_dir`, no program string. A metacharacter
   in a `/proc`-scraped value is then data because there is no parser left to make it code.
   Quoting is the weaker answer and prohibition 3 forbids it: it keeps the interpreter and
   makes the property depend on the escaper being right about every metacharacter for every
   emulator an operator's `$TERMINAL` might name.
2. **Name the third question, and check the rule.** The accessor's doc gains the distinction
   it lacked, and a census over `src/` reports any executable line that hands an interpreter
   an interpolated program. The doc states the rule; the census is what goes red for it.
3. **Make the carrier's certificate match its claim (WR-01).** The doc claims six absent
   conversions and the control certifies three. `Deref<Target = str>` is the one that matters:
   add it tomorrow and auto-deref restores the raw path at every site in the tree, with every
   test in this repository staying green.

**And one defect this fix would otherwise introduce, closed in the same commit.**
`find_terminal` returns `$TERMINAL` or one of four candidates, and the token separating the
emulator's own options from the program it runs is not the same for all of them. Moving from
one opaque program string to a real argv makes that difference visible for the first time;
handling it is what stops the security fix from silently becoming a feature deletion.

**What this plan does NOT touch, stated so the wave stays parallel.** `driver.rs`,
`driver_confirm.rs`, `screens/mod.rs` and `render_escape_guard.rs` belong to **21-28**
(CR-02, running in a parallel worktree in this same wave). The nine render-site files,
`src/ui/mod.rs`, `src/error.rs` and `src/state_reader/backlog.rs` belong to **21-29**
(WR-05/07/08, likewise parallel). CR-03's edit buffer is **21-30**, wave 2, because it also
lives in `detail.rs` and this plan owns that file first.
</objective>

## Assumption delta — FIRED (`chosen`), and the answer is `promote`

`gsd-tools query assumption-delta scan 21 --json` returned `detected: true`. Most of its
signals are `pluralization` matches against ROADMAP prose carried from the original phase
text and are not transitions in round 10's scope. **One is real and it is this plan's
subject**, and it is the `chosen` family: a value that had one derived answer now has a
chosen one.

- **The noun that is now primary:** *the question a raw accessor answers*. Round 9 built a
  two-question vocabulary — `shown()` for what a human reads, `as_raw_for_logic_only()` for
  everything else — and treated "everything else" as one class. CR-01 is the measurement
  that it is not one class. A lookup key, a map key and a path segment are inert. An argv
  element is inert. **A fragment spliced into a program an interpreter will parse is not**,
  and the accessor's doc listed all of them together.
- **The decision: `promote`.** The general representation — *three* questions, with the sink
  KIND named at every site — becomes primary, and the old two-question framing is demoted to
  the two cases it correctly covered. This is deliberately NOT `add-alongside`: adding a
  third accessor (`as_raw_for_a_shell`) would mint a supported way to do the unsafe thing.
  The promote is to the vocabulary and to the RULE — argv, never a program string — so that
  the third question has no site left in this codebase to be asked at.
- **The invariant test that encodes the generalised intent** (suggested and taken, Task 2):
  a census over `src/` reporting any executable line that hands a command interpreter an
  interpolated program. It is the machine-checkable form of "the third question has no
  sites", and it goes red for a fourth site nobody has written yet.
</assumption_delta_decision>
