<objective>
Close pass-7's gap 1 and gap 2 at their shared root: the character class is a hand-enumerated
22-code-point subset of the class its own doc names, and every fixture in six rounds was
sampled from inside it. This plan does the two things pass 7 proved no smaller thing can do:

1. **Derive the class** (level 4). `is_invisible_formatting_char` becomes a query against
   Unicode's own reference data (`Cf` ∪ `Default_Ignorable_Code_Point` via `icu_properties`
   compiled data), consumed by BOTH judgments — the emptiness half (`carries_visible_content`,
   criterion 1's own question, the half no round had named) and the identity half
   (`carries_invisible_formatting`).
2. **Move the sampling, not the literals** (the round's primary target). The falsifying corpus
   becomes an exhaustive all-codepoints sweep whose oracle is a SECOND, independently
   maintained derivation of the standard (`unicode-properties`, unicode-rs). The
   implementation and its falsifier no longer share a source, so a subset in either goes red
   against the other. This is the defect that recurred at three levels (arms, fields,
   character class) because every fixture agreed with the implementation by construction.
3. **Invert the identity direction** (level 5, adjudicated in 21-PREMISES.md Premise 8).
   Identities — aliases, run ids, phase tokens, everything `is_plain_path_component` judges —
   move to the allow-list `[A-Za-z0-9._-]`, which cannot be one code point short because the
   accepted set is finite. Free text keeps the derived deny-list, because a `--goal`
   legitimately carries arbitrary script. The user-visible trade (no non-ASCII aliases) is
   recorded at the site, in the refusal message, and in the SUMMARY — chosen, not discovered.

Everything structural pass 7 re-verified is load-bearing and untouched: `from_argv` stays
pure, above `drive`, twelve-field no-`..` destructure, six `NonBlank` fields; `execute_run`'s
ordering; the `Alias` newtype; guard ten. This plan changes what the predicates KNOW, not
where they sit.

**What level closes and what remains, stated honestly:** level 4 closes (the class is derived,
with a disclosed staleness bound: unassigned code points a future Unicode release makes Cf are
accepted in free text until the next dependency refresh). Level 5 closes for identities (a
finite alphabet terminates the enumeration). Below level 5 remains level 6 — stop letting user
bytes BE an identity at all (generated keys, display labels) — named in Premise 8 and NOT
planned here; and rendering-identity completeness is impossible in principle (fonts, shaping),
which is why TR39 confusables stay a separate roadmap item.
</objective>
