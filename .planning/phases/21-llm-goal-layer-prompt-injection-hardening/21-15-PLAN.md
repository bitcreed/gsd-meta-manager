<objective>
Close pass-5's three reproduced Criticals — CR-01, CR-02, IN-01 — by closing the **domain**, not
the instances. Four gap-closure cycles each protected a hand-enumerated subset of the argv-derived
values and each enumeration was exactly one item short: three `CommandSource` arms one at a time
(rounds 1–3), then three of `DriveArgs`'s six string fields (round 4). Round 4 proved the
*mechanism* (`NonBlank`, private field, single constructor) holds under attack; pass 5 proved the
*scope* was chosen by a human where it should have been chosen by the compiler.

Per the pass-5 verifier's recommendation, treated here as the design brief:

1. **`DriveArgs` becomes the domain.** All six argv-derived string fields are typed
   `payload::NonBlank`; a blank payload becomes unrepresentable in the value every downstream
   consumer reads — not just in the three fields `CommandSource` has variants for. The refusal
   moves to a single parse boundary, `DriveArgs::from_argv`, whose **exhaustive destructure** of
   the raw argv record makes a seventh field a compile error until somebody classifies it.
2. **`execute_run` stops re-deriving.** The source is resolved once, above every disk write;
   `recorded_command` and `digested_command_fragment` become total functions of `IterationSource`
   (two variants, no empty case), so the `(None, None) => String::new()` arms are deleted as
   unrepresentable rather than patched or reordered — CR-01's corruption path no longer exists to
   guard.
3. **One blankness predicate.** `text::carries_visible_content` becomes the only production
   spelling of the invisibility judgment; `is_plain_path_component` stops disagreeing with
   `NonBlank` about what blank means, which closes CR-02 (`--run-id '\u{200b}'` driving a
   complete run with an invisible directory name) at the seam that governs run ids, aliases, and
   re-read records alike.
4. **The enumeration machinery matches the new domain.** `DEGENERATE` is lifted to one shared
   const; the matrix grows to all seven invocation positions including the multi-flag row pass 5
   proved unexpressible.

Output: no argv payload without visible content can reach a render, a persisted record, or a run
directory name, in any of the six positions, singly or in combination — and adding a seventh
argv field without extending the protection is a compile error, not a sixth reviewer's discovery.
</objective>
