<objective>
Close round-4 CR-01 — the last blocker on ROADMAP criterion 1 — by closing the **class**, not
the arm. Three consecutive gap-closure cycles each fixed one `CommandSource` arm's blankness
(`Goal` in 21-07, `Command` in 21-11) and each left the next arm bare; the round-4 verification
reproduced `--target-phase '   '` previewing cleanly at exit 0 and, on a real run, creating
`run.lock`, a run directory, `journal.jsonl`, and a `run.json` carrying `"target_phase": "   "`
(a real corruption under D-30, where `""` means field-absent).

Per `21-PREMISES.md` (Premise 1: BROKEN), this plan does not add a fourth per-arm trim. It:

1. makes a blank payload **unrepresentable** — a `NonBlank` newtype with a private field and a
   single validating constructor, carried by all three `CommandSource` variants;
2. makes the anti-recurrence matrix **uniform and exemption-free** — every degenerate payload
   in every argv position is a `NoCommandSource` refusal, the column axis tied to
   `command_source`'s arity at compile time, the variant coverage tied to the single
   `ALL_VARIANT_NAMES` const (the verifier's named recommendation: make the column axis as
   structurally exhaustive as `variant_name` already made the row axis);
3. breaks the `trim` **tautology** — the detector and payload set stop sharing the production
   predicate, and zero-width payloads join `DEGENERATE` (round-3 WR-03);
4. closes the two adjacent same-class routes: `is_plain_path_component` accepting
   whitespace-only and control-carrying values (`--run-id '   '`, the embedded-newline render
   smuggle), and `approve_plan`'s `unwrap_or_default()` blank `target_phase` from the model seam.

Output: `--target-phase '   '` (and every degenerate sibling, in every position) exits with a
typed refusal, creates nothing, and is refused identically in preview and real mode — and a
fourth input shape reaching a render or a `run.json` field blank is a compile error or a named
red, never a reviewer's discovery.
</objective>
