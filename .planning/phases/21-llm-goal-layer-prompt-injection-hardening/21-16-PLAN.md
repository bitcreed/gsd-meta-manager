<objective>
Make the guard machinery as honest as the domain 21-15 closed, and add the one guard four cycles
never had: one that reads the **type** rather than a list. Pass 5 found four accuracy defects in
round 4's own guards — a boundary self-check blind to the tree's dominant visibility spelling
while claiming the region "provably empty" (WR-01, the third consecutive overclaiming header), a
non-vacuity bound that counts lines instead of needles, a hand-maintained variant const anchored
in only one direction, and a detector wearing credit for a falsification the literal array
performs. It also left `goal.rs`'s length-bound refusal with zero live coverage.

None of these is independently exploitable today; every one is what lets the NEXT reviewer be
told a region is clean when it is merely unchecked — the exact mechanism by which this phase's
Criticals kept shipping past green guards. This plan closes all five with self-testing controls
rather than better sentences, adds guard nine (`DriveArgs` declares no raw argv `String`), and
turns round-4's two violated prohibitions into standing assertions so a declared prohibition is
enforced rather than merely declared.

Output: a seventh argv field in the tree's declaration style, a blinded needle, a column-zero
post-marker `pub(crate)` item, a stale variant const, or a manufactured blank in a match arm
each produces a named red — the residual silent shapes (an aliased or off-style field, an
indented post-marker item) are named in each guard's limits block — and every guard's header
now describes exactly what its scan performs, no more.
</objective>
