## Per-gap: mechanism, or a narrower disclosed claim? G2, split into its two halves.

The orchestrator required this call per gap. G2 has two sub-parts that deserve different answers, and
collapsing them would have been the error.

| Sub-gap | Call | Why |
|---|---|---|
| **G2a — the CLI's short spelling `-r` (and `-r<value>`)** | **MECHANISM.** Teach the consumer both. | `-r` is the SAME option meaning the SAME thing; `claude --help` at 2.1.250 documents it as one option, `-r, --resume [value]`. There is no semantic ambiguity to disclose, only a spelling nobody wrote down. A narrower claim here would be documenting that this build cannot read a form a user will absolutely type. Measured safety: the complete short-option inventory is eight options and `-r` is the only `r`-initial one, so the attached form is unambiguous at this version. |
| **G2b — `--session-id <uuid>`, this build's executor's own spelling** | **MECHANISM, with a MEASURED rank rule and a DISCLOSED residual.** Teach it; rank it below `--resume`. | The narrower alternative — state in the class comment which producers the invariant covers and knowingly exclude the executor — was seriously considered and REJECTED, because the exclusion would have covered *this build's own driver*, which is the population DRIVE-01 is about. It is not an external launcher whose behaviour we can only guess at. What made the mechanism safe rather than a guess is that the rank rule is derived from a MEASURED help string rather than assumed: `--fork-session` documents that a resume REUSES the original id unless forking is requested, so on an argv carrying both, `--resume`'s value is the live conversation's identity. The premise is then ENFORCED (`fork-session` appears nowhere in `src/`, asserted) rather than remembered. **Disclosed residual:** an EXTERNALLY-launched `claude --resume X --fork-session` has a new id this build would report as `X`. Direction: **mis-detection**, bounded to externally-launched forked sessions, named at the constants and in `deferred-items.md`. |
| **The census itself** | **MECHANISM.** A source-derived adjudication table. | The narrower alternative — a prose sentence naming the two producers — is exactly what G2 IS: a remembered set. The whole point of the round is that the next unenumerated member recurs unless the set is measured. This is the same shape as this repository's existing `render_escape_guard` screen census and `text.rs` interpreter census, both of which have caught real unregistered members. |

## What is honestly NOT claimed by the census

The needle is a QUOTED OPTION LITERAL, not "an argv destined for `claude`". A producer that assembled
its option name from fragments, read it from a config value, or spelled it in a macro would be invisible
here. **Direction: under-detection, and silent.** The residual is bounded by the same anti-self-match
idiom `text.rs`'s interpreter census already discloses for its five interpolation markers, and it is
stated at the census in the source rather than only in this plan — because a census whose limits are
unwritten is the next round's gap.
