<objective>
Close the four Warnings and the two remaining warnings from verification pass 8 that are about
**what the tree says**, not what it does. Round 7's mechanisms are sound; five of the six defects
here are sentences that would get a correct mechanism removed or a correct fix reverted by a
maintainer who believed them.

Ordered by that harm, highest first:

1. **`narrow_visible`'s message diagnoses the opposite cause** (`tests/spawn_seam_guard.rs`).
   Verification pass 8 planted a bare field in the real `DriveArgs` body; the guard went red —
   correct — with a message saying the widening is matching something that is not a field
   declaration. It was not: a real field was added in the spelling round 7 widened
   `is_field_opener` to see. **An executor repairing under that message narrows `is_field_opener`
   back and undoes round 7's fix.** The verifier calls this the warning most likely to get a
   correct fix reverted; it is treated here as the highest-value item and it is ordered first.
2. **`WITNESS_ALLOWED_ELSEWHERE`'s doc overclaims** (WR-01). The table is DEFENSIBLE — a both-ways
   `assert_eq!` on a `BTreeMap`, governing a hygiene scan rather than a boundary, all four rows
   verified correct at HEAD — and it is **not** deleted. Its doc claims an allowed site cannot
   grow a second member of the set without breaking loudly. That is false in two directions it
   never names: the census counts *witnesses*, and it is per-*file*. This is 21-20's own
   prohibition 2 violated against 21-20's own diff, which is why this plan measures both
   residuals by planting them rather than asserting them.
3. **`hooks.rs`'s security rationale is now false** (WR-02). It justifies POSIX-quoting by saying
   `is_plain_path_component` accepts a quote character. Since D-19-2 it does not. A maintainer who
   checks that claim, finds it false, and concludes the quoting is redundant removes a real
   defence. The generated code is right; only the reason a reader trusts is wrong.
4. **A second spelling of the identity alphabet survives** (WR-03) at `src/envelope/advisory.rs`,
   gating GitHub owner/repo segments before they are interpolated into a request path, while
   `src/text.rs:155` claims to be the one spelling. Closed by making the claim TRUE — delegation —
   not by softening it.
5. **`carries_visible_content` does not disclose its free-text residual** (pass-8 warning). Free
   text keeps a deny-list bounded by a pinned Unicode version and thirteen hand-named
   default-ignorable members; a lone U+2800, private-use, unassigned or combining mark is
   accepted and renders as nothing. This phase's own standard is to name a residual with its
   direction, and this doc names the class it covers without naming what falls outside it.

Plus the record: the four **pre-existing** clippy lints, so their failure is never mistaken for
round-8 breakage; a new staleness obligation recording that the TUI's tolerance of invisible
characters is a property of the ratatui *version*; and criterion 4 re-surfaced unchanged.

**Wave 2, deliberately.** This plan re-measures counts across `src/` and `tests/` that 21-21's
diff moves, and both plans run the whole-suite gate in the same worktree. 21-20 serialized for
the same two reasons. Running after 21-21 also means WR-01's rewritten residual statements are
measured against the tree that ships, not against a tree that is about to change.
</objective>
