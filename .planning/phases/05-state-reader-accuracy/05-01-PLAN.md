    Note: `path` comes FIRST as the required positional arg, `alias` second as optional. This changes the CLI from `gsd-manager add <alias> <path>` to `gsd-manager add <path> [alias]` per D-04.

    **main.rs handler (line 41):** Update the Add match arm:
    ```rust
    Some(Commands::Add { path, alias }) => {
        let canonical_path = path.canonicalize().unwrap_or(path);
        let alias = alias.unwrap_or_else(|| {
            canonical_path
                .file_name()
                .and_then(|n| n.to_str())
                .unwrap_or("unnamed")
                .to_string()
        });
        // Check for alias uniqueness
        let config = load_config(&config_path)?;
        if config.projects.contains_key(&alias) {
            eprintln!("Error: alias '{}' already exists. Provide an explicit alias: gsd-manager add {} <alias>", alias, canonical_path.display());
            std::process::exit(1);
        }
        let mut config = config;
        add_project(&mut config, &alias, &canonical_path)?;
        save_config(&config, &config_path)?;
        println!("Added project '{}' at {}", alias, canonical_path.display());
    }
    ```
    Key: check for duplicate alias before adding. If auto-derived alias conflicts, print error with instruction to provide explicit alias (per Pitfall 5 from research).
