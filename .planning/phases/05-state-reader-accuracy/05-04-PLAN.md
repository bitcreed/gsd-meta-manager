       `fn prev_status(threshold: DiskStatus) -> DiskStatus` — maps each DiskStatus to its predecessor:
       - Discussed -> Empty, Researched -> Discussed, Planned -> Researched, Partial -> Planned, Complete -> Partial, _ -> NoDirectory

       `fn compact_pipeline(status: &DiskStatus) -> Line<'static>` — renders 5 spans (" D ", " R ", " P ", " E ", " V ") with colors:
       - Green if `*status >= *threshold` (completed stage)
       - Yellow if `*status == prev_status(*threshold)` (current stage)
       - DarkGray otherwise (not reached)

       `fn expanded_status(inference: &DiskInference) -> String` — returns human text:
       - NoDirectory -> "Not started", Empty -> "Empty", Discussed -> "Discussed", Researched -> "Researched"
       - Planned -> format!("Planned ({} plans)", inference.plan_count)
       - Partial -> format!("Executing {}/{}", inference.summary_count, inference.plan_count)
       - Complete -> "Complete"

       d. Compute `is_milestone_complete`: `state.completed_phases >= state.total_phases && state.total_phases > 0`
       e. Build `status_cell: Line` with three branches:
          - If `is_milestone_complete`: Line with milestone name + " Complete" in DarkGray (per D-03)
