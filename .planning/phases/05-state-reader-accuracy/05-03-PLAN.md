    ```rust
    #[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Default)]
    pub enum DiskStatus {
        #[default]
        NoDirectory,
        Empty,
        Discussed,
        Researched,
        Planned,
        Partial,
        Complete,
    }

    #[derive(Debug, Clone, Default)]
    pub struct DiskInference {
        pub status: DiskStatus,
        pub plan_count: u32,
        pub summary_count: u32,
        pub has_context: bool,
        pub has_research: bool,
        pub has_verification: bool,
    }
    ```

    Implement `pub fn infer_disk_status(phase_dir: &Path) -> DiskInference` following GSD's algorithm from `roadmap.cjs:127-166`:
    1. If `phase_dir` is not a directory, return NoDirectory
    2. Read directory entries, collect filenames as strings
    3. Count files matching `*-PLAN.md` or `PLAN.md` -> plan_count
    4. Count files matching `*-SUMMARY.md` or `SUMMARY.md` -> summary_count
    5. Check for `*-CONTEXT.md` or `CONTEXT.md` -> has_context
    6. Check for `*-RESEARCH.md` or `RESEARCH.md` -> has_research
    7. Check for `*-VERIFICATION.md` or `VERIFICATION.md` -> has_verification
    8. Determine status: if summary_count >= plan_count && plan_count > 0 -> Complete; else if summary_count > 0 -> Partial; else if plan_count > 0 -> Planned; else if has_research -> Researched; else if has_context -> Discussed; else -> Empty

    Implement `pub fn find_phase_dir(planning_dir: &Path, phase_number: &str) -> Option<PathBuf>`:
    1. Look in `planning_dir/phases/` for directories starting with zero-padded phase number (e.g., `05-`)
    2. If not found, check `planning_dir/milestones/*/` for archived phases
    3. Return the first match, or None

    Implement `pub fn infer_phase_status(planning_dir: &Path, phase_number: &str) -> DiskInference`:
    1. Call `find_phase_dir` to locate the phase directory
    2. If found in milestones archive, return Complete status directly (archived = done, per Pitfall 4)
    3. Otherwise call `infer_disk_status` on the found directory
    4. If no directory found, return NoDirectory

    ```rust
    fn compact_pipeline(status: &DiskStatus) -> Line<'static> {
        let stages: [(& str, DiskStatus); 5] = [
            ("D", DiskStatus::Discussed),
            ("R", DiskStatus::Researched),
            ("P", DiskStatus::Planned),
            ("E", DiskStatus::Partial),
            ("V", DiskStatus::Complete),
        ];

        let spans: Vec<Span> = stages.iter().map(|(label, threshold)| {
            let color = if *status >= *threshold {
                Color::Green       // completed stage
            } else if *status == prev_status(*threshold) {
                Color::Yellow      // current stage
            } else {
                Color::DarkGray    // not reached
            };
            Span::styled(format!(" {} ", label), Style::default().fg(color))
        }).collect();

        Line::from(spans)
    }
    ```

    Add helper `prev_status` that returns the DiskStatus one step below the given threshold (e.g., prev of Discussed = Empty, prev of Complete = Partial).

    Add expanded status function for focused rows:
    ```rust
    fn expanded_status(inference: &DiskInference) -> String {
        match inference.status {
            DiskStatus::NoDirectory => "Not started".to_string(),

            DiskStatus::Discussed => "Discussed".to_string(),
            DiskStatus::Researched => "Researched".to_string(),
            DiskStatus::Planned => format!("Planned ({} plans)", inference.plan_count),
            DiskStatus::Partial => format!("Executing {}/{}", inference.summary_count, inference.plan_count),
            DiskStatus::Complete => "Complete".to_string(),
        }
    }
    ```
