<objective>
Make the keys discoverable, surface the dry-run report where a start is about to happen, and prove
mechanically that the phase did not grow the lint count, the dependency list, or an unpruned map.

Purpose: `help.rs` is a hardcoded line vector in a centred popup **with no scrolling**. It already
holds around thirty rows, and at an eighty-by-twenty-four terminal the popup is forty-eight by
sixteen, so roughly half is already invisible. This phase adds about fourteen rows — a Driver key
section, the sort toggle, two filter rows, a badge legend and an injection-state legend. Adding them
to a screen that cannot show them is a documentation change with no reader, so the scroll work is
required rather than nice to have.

The dry-run preview is the phase's **designated cut** (D-26): it is TRANS-05-adjacent and cheap, and
Phase 17 explicitly left "the TUI surfacing dry-run output" to this phase, but it is the only surface
item with no requirement id. It ships here, last, so that if it had competed for space with the nine
requirements it would have been dropped without disturbing anything else.

Output: a readable help screen, the dry-run preview, and the phase's mechanical close-out.
</objective>
