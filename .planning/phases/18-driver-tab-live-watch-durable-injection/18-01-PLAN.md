<objective>
Prove the phase's spine end to end with one production-quality vertical slice: a human-authored
message written to a file on disk reaches a live agent's stdin and is recorded as evidence — and
close the reproduced path-traversal hole (D-27 / WR-02) in the same breath, because this plan is
what adds the sixth path-joining caller and it must not be added unvalidated.

Purpose: **The TUI holds no handle on the run** (D-03). `ExecutionHandle::stdin_tx` lives only
inside the detached driver process; the TUI and the driver share exactly one primitive, the
filesystem. So the injection path is necessarily TUI → `inbox.jsonl` → driver tail →
`Executor::send` → journal → TUI. There is no shortcut, and any design in which the TUI "sends"
anywhere other than to a file cannot survive a TUI restart and therefore cannot satisfy STEER-03.
Separately, `src/driver/run.rs` closes the child's stdin immediately after spawn; **while that
stands, STEER-01/02/03 are physically impossible** — `Executor::send` returns `WriterGone`. D-11
changes when stdin closes. A plan set that renders a beautiful injection UI without this change
delivers nothing, and it will look complete.

Output: a fallible `run_paths`, a new `src/journal/inbox.rs`, the relocated `close_input`, the
drain-loop inbox arm, the widened + extended journal schema, and two new integration test files.

omission: the ROADMAP marks research "optional — decide at planning time", and every external

## Assumption-Delta Decision (advisory, recorded)

The detector fired (`pluralization`, `optional`). Two real transitions in this phase:

1. **`DriverStartRequested.command`: a constant becomes a parameter** (`chosen`). The generalized
   noun is **the GSD command to run**, not "the default drive command".
   **Decision: `promote`.** `DEFAULT_DRIVE_COMMAND` is demoted to the picker's default *selection*;
   the command threaded through `Action` / `drive_argv` / `RunRecord.gsd_command` becomes the
   primary. No caller keeps the constant as its only source.
2. **`run_paths` becomes fallible** (`required → optional`). The generalized noun is **a validated
   run id**. **Decision: `promote`** — `Option<RunPaths>` is the only shape; no infallible variant is
   kept alongside, because keeping one is exactly how the fifth caller escapes validation.

No `add-alongside` debt is accepted in this phase.
