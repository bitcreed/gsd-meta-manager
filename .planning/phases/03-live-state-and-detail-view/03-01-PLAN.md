   - `pub struct FileWatcher` wrapping `notify_debouncer_full::Debouncer<notify::RecommendedWatcher, notify_debouncer_full::RecommendedCache>`
   - `FileWatcher::new(tx: tokio::sync::mpsc::UnboundedSender<Action>) -> anyhow::Result<Self>` that creates a debouncer with 200ms timeout (per D-05). The closure callback extracts the project root from changed paths and sends `Action::FileChanged { project_path }` via `tx.send()`. Key insight: `UnboundedSender::send()` is non-async and safe to call from the notify callback thread.
   - `pub fn watch(&mut self, planning_dir: &Path) -> anyhow::Result<()>` using `RecursiveMode::Recursive`
   - `pub fn unwatch(&mut self, planning_dir: &Path) -> anyhow::Result<()>`
   - `fn extract_project_root(path: &Path) -> Option<&Path>` helper that walks up from a changed file to find the parent of `.planning/` directory
   - Wrap watch errors with `tracing::warn!` (per RESEARCH.md Pitfall 3: paths that become unavailable should log, not crash)

4. Add `pub mod watcher;` to `src/lib.rs`.
