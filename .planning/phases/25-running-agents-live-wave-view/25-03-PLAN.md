<objective>
Derive the per-project wave model (D-A01 wave part, D-A02, D-C10, D-C11): attribute each agent to a
plan at scan time, mark plans whose SUMMARY sits unmerged in an agent's worktree, and turn the scan
plus the already-parsed `ProjectState` into an `AgentView` — wave rows, plan-state counts, display-

(25-05) render.

needs (commit scopes, the worktree SUMMARY stat) happens in the scan.

`DiskInference.summarized_plans`, `git_ops::log_subjects`, `tests/agents_waves.rs`.
