## Spacing Scale

Terminal cell units (1 cell = 1 character width or height). All spacing in whole cells.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 1 cell | Inline padding between icon and text |
| sm | 2 cells | Column gaps in dashboard table |
| md | 3 cells | Section padding within detail view |
| lg | 4 cells | Layout margins (detail view sides) |

Exception: Terminal cell units use a base-1 character grid. Standard base-4 pixel constraints do not apply. Values xs=1, sm=2, md=3, lg=4 represent the minimum practical increments for a monospace cell layout. These match existing ratatui layout patterns in the codebase.

## Color

ANSI terminal colors. Follows existing status color vocabulary established in `normal.rs:status_color()`.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | Terminal default bg | All surfaces, backgrounds |
| Secondary (30%) | `Color::DarkGray` | Borders, separators, dim text, completed items |
| Accent (10%) | `Color::Cyan` | Pause badge icon, pause badge text |
| Active status | `Color::Green` | Active session indicator (existing) |
| Idle status | `Color::Yellow` | Idle project rows (existing) |
| Blocked status | `Color::Red` | Blocked project rows (existing) |
| Unknown status | `Color::Magenta` | Unknown status rows (existing) |

Accent (Cyan) reserved for:
- Pause badge icon (`\u{23F8}` / `⏸`) prepended to alias cell
- Pause context string in detail view status area
- Summary bar "done" count (existing usage, no conflict)

### Badge Priority Rule

When a project has BOTH an active Claude session AND a HANDOFF file:
- **Pause badge wins.** Display `⏸` in Cyan, suppress `▶` session indicator.
- Source: CONTEXT.md decision + ROADMAP.md success criteria #2.

## Interaction Contract

### Dashboard Row (normal.rs)

**State: Project not paused, no session**
```
  my-project   Phase 3/5   D-R-P-E-V   [====......] 40%   0
```

**State: Project has active session (existing)**
```
  ▶ my-project   Phase 3/5   D-R-P-E-V   [====......] 40%   0
```

**State: Project is paused (new)**
```
  ⏸ my-project   Phase 3/5   D-R-P-E-V   [====......] 40%   0
```
Where `⏸` renders in `Color::Cyan`.

**State: Project is paused AND has active session (priority rule)**
```
  ⏸ my-project   Phase 3/5   D-R-P-E-V   [====......] 40%   0
```
Pause wins. Session indicator suppressed.

### Detail View (detail.rs)

**State: Project is paused with context**
```
  Status: verifying
  Paused: Fix the state reader timeout before continuing
```
Where "Paused: {context}" renders in `Color::Cyan` with `Modifier::BOLD` on the "Paused:" label.

**State: Project is paused without extractable context**
```
  Status: verifying
  Paused (HANDOFF file present)
```
Fallback copy when context extraction fails or HANDOFF file has no parseable next_action.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Dashboard badge | `⏸ ` (U+23F8 DOUBLE VERTICAL BAR + space, Cyan) |
| Detail pause label | `Paused: ` (bold Cyan, followed by context in regular Cyan) |
| Detail pause fallback | `Paused (HANDOFF file present)` (Cyan) |
| Empty state | Not applicable -- phase adds a badge to existing rows, no new empty states |
| Error state | Not applicable -- detection failure degrades silently (no badge shown, no error displayed) |
| Destructive actions | None in this phase |

### Pause Context Extraction (Claude's Discretion)

For `HANDOFF.json`:
- Parse JSON, extract `next_action` field value
- Truncate to 60 characters on dashboard, full text in detail view

For `HANDOFF.md`:
- Extract first non-empty line after any `#` heading, or first non-empty line if no heading
- Truncate to 60 characters on dashboard, full text in detail view

If extraction fails for either format, use fallback copy.
