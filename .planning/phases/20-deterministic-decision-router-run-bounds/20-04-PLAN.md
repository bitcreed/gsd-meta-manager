<objective>
Widen the tracer's single rule into the complete deterministic rule table, give every
human-judgement gate its own named park, define goal-met as a machine-checkable fact, and prove
the whole table agrees with the runtime the driver is actually driving.

Research found the rule table already exists authoritatively — in GSD's own runtime, computed with
no model call — and confirmed it live against this repository. That table, not a hand-written one
derived from prose, is the specification. Calling it from the run loop is forbidden (it is a second
project-state reader, a blocking subprocess on an async path, and a Node process inside a loop whose
whole value is surviving its parent), so it is used as a *test-time oracle* instead. That oracle is
also the durable answer to the staleness that made an earlier design obsolete: it converts an expiry
date in a document into a failing build.

Purpose: this is ROADMAP criteria 1 and 5. Determinism is proven as a value property, and the
always-park posture is made measurable rather than merely asserted.
Output: the complete rule table with a both-directions guard, the closed gate taxonomy, the goal-met
predicate, the declared safe command alphabet, and the conformance oracle.
</objective>

Create `tests/driver_router_table.rs` as an integration test — it reads the source tree, and a test that walks the source has no business living inside it. It carries four guards, each in the register `tests/spawn_seam_guard.rs` establishes:

A rule with no row is a violation and a row that produces nothing is equally a violation — an allowlist wider than the truth it describes is the failure this shape exists to catch.

The disjointness guard. For every pair of rows, construct the observed states each accepts and assert no state is accepted by both, so the "same state always yields the same choice" claim is a property of the table rather than a consequence of arm ordering.

The alphabet guard. Scan the router's source for command-shaped string literals with a word-boundary matcher rather than a naive substring search, skipping comment lines, and assert the observed set equals the declared alphabet exactly — failing in both directions. Include the non-vacuity floor and a control arm proving the matcher fires on a synthetic offending snippet and spares a synthetic clean one.

The empty-input guard. Assert a project state with an empty phases vector, one whose phase map lacks the target key, and one whose phase map is empty each yield a park naming the observed state, with no panic and no command.
