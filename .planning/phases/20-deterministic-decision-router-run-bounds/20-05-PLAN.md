<objective>
Make a run that hits a Claude subscription quota park, name the window that blocked it and when
it resets, and stop.

Research resolved the protocol from committed captures and the installed binary's own string table
rather than from documentation: the signal is a separate top-level stream type carrying a window
type, a status and a reset time, and the five-hour and seven-day windows *are* distinguishable. It
also found the plumbing gap precisely — the event is parsed, forwarded to the driver and journaled,
but is never collected into the envelope vector the outcome derivation consumes, so the park cannot
be derived there. The honest seam is the driver's own drain loop, which already receives the event
and already inspects events. Widening the one outcome entry point to reach it would recreate the
shape of a bug that path was deliberately narrowed to prevent.

Purpose: this is ROADMAP criterion 4, and it is the only bound that protects a resource shared with
every other Claude surface the user has.
Output: a pure classifier for the payload, an observation in the drain loop, a park that does not
retry, and a labelled synthesised fixture for the one status no capture exists for.
</objective>
