journal lister or the dry-run preview. 31-04 can then delete those modules outright. The Phase 30
launcher markers and launcher run list are the replacement and must stay green.

`ProjectViewCache` and `AppContext` without legacy fields, and `classify_change` ignoring
`runs/**`.
