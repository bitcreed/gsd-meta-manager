1. Create `src/state_reader/queue_md.rs`:

   ```rust
   #[derive(Debug, Clone)]
   pub struct QueuedAction {
       pub command: String,
   }
   ```

   `pub fn parse_queue_md(content: &str) -> Vec<QueuedAction>`:
   - Read lines, trim whitespace
   - Skip empty lines
   - Skip lines starting with `#` (comments, including the `# Queue` header)
   - Strip leading `- ` prefix if present
   - Each remaining line becomes a `QueuedAction { command: line.to_string() }`

   `pub fn write_queue_md(actions: &[QueuedAction]) -> String`:
   - Start with `# Queue\n\n`
   - Each action: `- {command}\n`
   - Return the full string

   `pub fn load_queue(planning_dir: &std::path::Path) -> Vec<QueuedAction>`:
   - Read `planning_dir.join("QUEUE.md")`
   - If file doesn't exist or read fails, return empty vec
   - Parse with `parse_queue_md`

   `pub fn save_queue(planning_dir: &std::path::Path, actions: &[QueuedAction]) -> anyhow::Result<()>`:
   - Generate content with `write_queue_md`
   - Atomic write: write to `QUEUE.md.tmp` in same directory, then `std::fs::rename` to `QUEUE.md` (per Pitfall 5 from research)
   - If `.planning/` dir doesn't exist, return error with message "Run GSD in this project first to enable queue" (per Open Question 2 from research)

   `pub fn suggest_next_commands(state: &super::ProjectState) -> Vec<String>`:
   Per D-09, suggest based on project status:
   - Status contains "ready to plan" or "idle": suggest `/gsd:discuss-phase {N}`, `/gsd:plan-phase {N}` where N = completed_phases + 1
   - Status contains "executing" or "active": suggest `/gsd:execute-phase {N}`, `/gsd:verify-work {N}`
   - Status contains "complete" or "done": suggest `/gsd:progress`
   - Default fallback: suggest discuss, plan, execute for next phase
   - Always include `/gsd:quick` as a generic suggestion at the end

2. In `src/state_reader/mod.rs`:
   - Add `pub mod queue_md;`
   - Add `pub queued_actions: Vec<queue_md::QueuedAction>` to `ProjectState` struct (with `Default` via empty vec)
   - In `parse_project_state`, after parsing other files, call `queue_md::load_queue(planning_dir)` and assign to `state.queued_actions`
