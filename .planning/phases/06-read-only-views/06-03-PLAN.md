1. In `src/ui/screens/detail.rs`, implement the Git tab rendering. Add a helper function:

   `fn render_git_tab(frame: &mut Frame, area: Rect, alias: &str, ctx: &AppContext)`

   This function:
   a. Gets `ProjectViewCache` from `ctx.view_cache`. If none, show "Press 4 to load git history".
   b. If `cache.loading_git`, render dim "Loading git history..." Paragraph.
   c. If `cache.git_entries` is empty and not loading, render "No commits found (or not a git repository)" Paragraph.
   d. Render a mode indicator line at top of area (Length 1):
      - If `cache.git_planning_only`: yellow text `"  [.planning/ only]  Press 'p' to show full repo"`
      - Else: dim text `"  [Full repo]  Press 'p' to show .planning/ only"`
   e. If `cache.git_diff_stat` is Some (per D-08 inline split pane):
      - Split remaining area: top 60% for log list, bottom 40% for diff stat
   f. Else: full remaining area for log list

   For the log list (per D-06 one-line format):
   - Each entry rendered as a `Line` with styled spans:
     - `Span::styled(entry.hash, Style::default().fg(Color::Yellow))` -- 7-char hash
     - `Span::raw(" -- ")`
     - `Span::raw(&entry.date)`
     - `Span::raw(" -- ")`
     - `Span::raw(&entry.message)`
     - `Span::raw("  ")`
     - `Span::styled(&entry.author, Style::default().fg(Color::DarkGray))` -- author dimmed per D-06
   - Use ratatui `List` widget with highlight on selected entry (cyan + bold)
   - Render with `frame.render_stateful_widget(list, log_area, &mut list_state)` where list_state selects `cache.git_selected`

   For the diff stat pane (when visible):
   - Block with title `" Diff: {hash} "` and borders ALL
   - Content: Paragraph showing each line from `stat.file_stats` vector, followed by a summary line:
     `"{files_changed} files changed, +{insertions} -{deletions}"`
   - Summary line styled: insertions in green, deletions in red
   - If `cache.loading_diff`, show dim "Loading diff..."

2. Wire render_git_tab into the main `render` method's GitHistory match arm (replacing placeholder from Plan 01).

3. In `handle_key`, add Git-tab-specific key handling:
   a. When on Git tab and `KeyCode::Char('j')` or `KeyCode::Down`: increment `git_selected` (clamped to entries.len()-1), clear `git_diff_stat` (different commit selected)
   b. When on Git tab and `KeyCode::Char('k')` or `KeyCode::Up`: decrement `git_selected`, clear `git_diff_stat`
   c. `KeyCode::Enter` on Git tab (per D-08): if git_entries is non-empty, get selected entry's hash, set `loading_diff = true`, spawn async task:
      ```rust
      if let Some(tx) = &ctx.event_tx {
          let tx = tx.clone();
          let alias = self.alias.clone();
          let hash = selected_hash.to_string();
          let project_path = project_path.clone();
          tokio::spawn(async move {
              if let Ok(stat) = crate::state_reader::git_ops::load_diff_stat(&project_path, &hash).await {
                  let _ = tx.send(Action::GitDiffStatLoaded { alias, hash, stat });
              }
          });
      }
      ```
   d. `KeyCode::Char('p')` on Git tab (per D-07): toggle `git_planning_only`, clear `git_entries` and `git_diff_stat`, set `loading_git = true`, spawn async reload:
      ```rust
      if let Some(tx) = &ctx.event_tx {
          let tx = tx.clone();
          let alias = self.alias.clone();
          let planning_only = new_planning_only_value;
          let project_path = project_path.clone();
          tokio::spawn(async move {
              if let Ok(entries) = crate::state_reader::git_ops::load_git_log(&project_path, planning_only, 50).await {
                  let _ = tx.send(Action::GitLogLoaded { alias, entries, planning_only });
              }
          });
      }
      ```
   e. `KeyCode::Esc` on Git tab when diff stat is showing: clear `git_diff_stat` (dismiss diff pane) instead of popping screen. Only pop if no diff pane visible.

4. On first switch to Git tab (in handle_key tab-switch logic from Plan 01): if cache has no entries and is not loading, check for `.git` directory in project path. If no `.git`, set entries to empty vec (will show "not a git repository" message). If `.git` exists, set `loading_git = true`, spawn async load of `load_git_log(project_path, false, 50)` via event_tx, sending `GitLogLoaded` action back.

5. Also update `render_main_only` to include git tab rendering.

6. Verify `src/state_reader/git_ops.rs` handles edge cases:
   - `load_git_log`: returns empty Vec on non-zero exit (no git repo, empty repo)
   - `load_diff_stat`: returns Default GitDiffStat on error
   - Both use `tokio::process::Command` (NOT std::process::Command)
